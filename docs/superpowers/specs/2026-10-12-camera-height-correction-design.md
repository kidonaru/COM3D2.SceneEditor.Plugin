# カメラの身長補正 設計

## 目的

作成時と身長の違うメイドでタイムラインを再生したときに、カメラの構図（注視点の高さ）が合うようにする。主な用途は、配布されたタイムラインや過去に作ったタイムラインを別のメイドで流用すること。

成功の条件:

- 背の高いメイドで作ったタイムラインを背の低いメイドで再生しても、注視点の高さがメイドに合う
- メイドが複数いるタイムラインで、カットごとに映しているメイドの身長に合わせられる
- 補正 ON のまま別のメイドで編集・保存しても、作者の環境で再生した構図が崩れない
- 旧 XML・MTE データの見た目は変わらない

## 改訂の経緯

初版では補正の設定（ON/OFF・基準メイド・基準身長）をタイムライン単位で 1 組だけ持っていた。これでは、メイド A と B を別々のカットで映すタイムラインで、片方だけ身長が違うメイドに替えると、もう片方の倍率で補正されて構図がずれる。

そこで「どのメイドに合わせるか」を、手ブレと同じくカメラレイヤーの独立した項目のキーで持つ形に改めた。初版の実装は未リリースのため、初版の XML 要素の読込互換は持たない。

## 仕様

### 身長補正の項目（カメラレイヤー）

カメラレイヤーに 3 つ目の項目 `身長補正` を足す。項目は `カメラ` / `手ブレ` / `身長補正` になる。

| 値 | 型 | 既定 | 内容 |
|---|---|---|---|
| 基準メイド | int | -1（補正なし） | 補正の基準にするメイドのスロット番号 |

- キーに入れるのは基準メイドのスロット番号だけ。基準身長はキーに入れない
  - 入れると、別のメイドで編集してキーを打ったときに基準身長が今のメイドの身長に置き換わり、同じ区間にある他のカメラキーの解釈まで変わってしまうため
- 身長補正のキーは、UI で基準メイドを「キーで当たっている値」（キーが無ければ -1）から変えたときだけ書く。書く値はライブ値（下記）
  - 変えていないのに書くと、補正を使わないタイムラインにも身長補正のキーが入り、MTE で開けなくなる。新規レイヤーのフレーム 0 にも入れない
  - 補間の途中でも、UI を触っていなければライブ値はキーで当たっている値のままなので書かれない。書くとそのフレームが補間から外れ、今の補間で逆補正したカメラのキーとずれる
  - 編集開始時のスナップショットには身長補正のボーンを入れない。入れると、編集モードに入る前に選んだ基準メイドが差分にならず、カメラだけ動かした差分登録で身長補正のキーが書かれない
- キーが無いフレームでは、ライブ値をそのまま使う（手ブレと同じ）

### ライブ値

- 今の基準メイドのスロット番号。Camera ウィンドウの `Main` タブと Inspector の UI で選ぶ
- 再生でキーを適用すると、ライブ値も区間の始点のキーの値になる
- タイムラインを新規作成・読込・アンロードしたときだけ -1 に戻す。Undo / Redo では戻さない（身長補正のキーが無いタイムラインで Undo するたびに、基準メイドが「なし」に戻ってしまうため）

### 基準身長（タイムライン単位、スロットごと）

| 項目 | 型 | 既定 | 内容 |
|---|---|---|---|
| 基準身長 | スロット番号 → int (cm) | 空 | 作成時の、そのスロットのメイドのゲーム内身長 |

- そのスロットの基準身長が未設定のとき、UI でそのスロットを基準メイドに選んだ時点で 1 回だけ取り込む
  - キーを打つときには取り込まない。キーの値を作る処理は、編集開始時のスナップショットなどキーを打たない場面でも走り、履歴の外でタイムラインを書き換えてしまうため
- 設定済みの基準身長は、保存・キー打ち・選び直しでは上書きしない。上書きすると、別のメイドで開いて操作しただけで作者の基準が失われるため
- `取得` ボタンで、今の基準メイドの身長を手動で取り込み直せる
- 基準身長は Undo / Redo の対象にしない。Undo / Redo でも今の値を引き継ぎ、履歴の差分比較からも外す（シェーダー変更と同じ扱い）。比較に含めると、変更後の最初のキー編集の Undo が全再構築に倒れ、基準身長まで古い値へ戻るため
- 作者の環境では全員の倍率が 1 になり、キーの注視点はただのワールド座標になる。そのため、後から区間の基準メイドを付け替えても、作者の環境での見た目は変わらない

### 身長の求め方

- 身長はゲーム内の身長値（プロフィールに出る cm）で測る。骨スケール系プラグインで脚などを伸ばしたぶんは考慮しない
- ゲームはプロフィールの身長を、旧ボディ（`Status.UpdateBodyParam`）でも CRC ボディ（`BodyProfileManager.Height`）でも同じ式で求める
  - 式: `(int)((1340 + sintyou·4 + DouPer·(1 + sintyou·0.005) + KubiScl·0.5 + HeadY·0.5) / 10)`
- SceneEditor はこの式をメイドの今の props から直接計算する
  - `status.body.height` は使わない。`UpdateBodyParam` が呼ばれたときしか更新されず、SceneEditor で体型を変えた後も古い値のまま残るため
  - `UpdateBodyParam` も呼ばない。セーブデータになる `status` の体重やバストなども書き換えてしまうため

### 1 人ぶんの補正

基準メイドがスロット k のとき、倍率と補正は次のとおり。

- `s_k = スロット k のメイドの今の身長 / スロット k の基準身長`
- `Correct_k(y) = r_k + (y − r_k) · s_k`（r_k はスロット k のメイドのルート Transform の Y）
- 次のいずれかに当てはまるときは補正しない（`Correct_k(y) = y`）
  - 基準メイドが -1
  - スロット k の基準身長が未設定または 0 以下
  - スロット k にメイドがいない
  - スロット k のメイドの身長が 0 以下
- ボディのロード状態は条件にしない。身長は props から求まるので、着替えでボディを再ロードしている間もカメラが跳ねない

### 補間

- 身長補正のキーの区間では、始点のキーのメイド A と終点のキーのメイド B の補正結果を線形補間する
  - `w = (今の時刻 − 区間の始点の時刻) / (区間の長さ)`（線形。タンジェントは持たない）
  - `y' = (1 − w) · Correct_A(y) + w · Correct_B(y)`
  - 補正しない側は `Correct(y) = y` として同じ式でつなぐ。ON/OFF の切り替えもなめらかになる
- スロット番号そのものは補間しない
- カットで切り替えたいときは、他のレイヤーと同じく隣り合うフレームにキーを打つ
- 最後のキーより後は最後のキーの値を使う。最初のキーより前は、身長補正もカメラのキーも適用されない（他の項目と同じ）

### 補正のかけ方（メインカメラのみ）

- 再生時の適用順は「手ブレ → 身長補正 → カメラ」。身長補正は、その時刻の補間の状態（A・B・w）を決めるだけで、カメラに直接は書かない
- **追従なしのカメラキー**: 注視点の Y に上の補間をかける
- **追従キー**: 補正しない。追従先の部位がもともと身長に合わせて動いているため
- 次の値は補正しない: 注視点の XZ、距離、FOV、ロール
- **キーを打つとき**（`CameraTimelineLayer.UpdateFrame`）: 追従なしのカメラキーは、その時刻の補間の逆をかけて Y を保存する
  - 補間は y の 1 次式 `y' = S·y + R` になる
    - `S = (1 − w)·s_A + w·s_B`
    - `R = (1 − w)·r_A·(1 − s_A) + w·r_B·(1 − s_B)`
  - 逆は `y = (y' − R) / S`。S は正の倍率の重み付き平均なので常に正
- サブカメラは対象外
- カメラ構図のプリセット（Camera ウィンドウの 10 スロット）には含めない

### 既知の制約

- 身長補正のキーが当たっている間、編集モードの外では UI で選んだ基準メイドがキーの値に戻る（手ブレと同じ）。基準メイドを変えるときは、編集モードで選んでからキーを打つ
- 基準身長はタイムライン単位なので、基準身長の違うタイムラインへカメラキーを貼り付けると高さがずれる

### XML 互換

- 身長補正のキーは新しい `TransformType.CameraHeight`（値数 1）で保存する。version は上げない
  - これを含む XML は、MTE・旧 SE では未知の enum 値（`<Type>CameraHeight</Type>`）でデシリアライズに失敗する（手ブレの `CameraShake` と同じ扱い）
- 基準身長はルートの `<CameraHeightBases>`（要素ごとに `MaidSlotNo` / `Height`）で保存する。空なら書き出さない
- 要素やキーの無い XML（旧 SE・MTE）は、補正なしとして読む
- 初版の `IsCameraHeightCorrection` / `CameraHeightMaidSlotNo` / `CameraHeightBase` は削除する（未リリースのため読込互換は持たない）
- CLAUDE.md の「タイムライン XML の互換方向」の項目を書き直す

## 構成

| 単位 | 責務 |
|---|---|
| `CameraHeightCorrection`（static・Unity 非依存） | 身長の式、`s` の算出、1 人ぶんの `Correct`、2 人の補間 `Blend` とその逆 `Unblend`。単体テストの対象 |
| `TransformDataCameraHeight`（新規） | 身長補正のキー（基準メイドのスロット、値数 1、タンジェントなし） |
| `TimelineData` / `TimelineXml` | スロットごとの基準身長の保持と XML の読み書き |
| 身長補正のライブ値（新規、`CameraShakeManager` に相当） | ライブの基準メイドと、再生で決まった補間の状態（A・B・w）を持つ |
| `CameraTimelineLayer` | 項目 `身長補正` の追加。`ApplyMotion` で補間の状態を決め、追従なしの分岐で補正する。`UpdateFrame` で逆補正し、身長補正のキーを書く |
| `CameraHeightRowDrawer` | 基準メイド（「なし」+ メイド）の選択・基準身長の欄・`取得` ボタン・今の身長と倍率の表示 |
| `CameraItemInspector` / `CameraWindow` | カメラ項目の Inspector と Camera ウィンドウの `Main` タブに設定行を置く。`身長補正` 項目だけを選んだときの Inspector も設定行を出す |

## テスト

**単体テスト**（`COM3D2.SceneEditor.Plugin.Tests`）

- 身長の式がゲームと同じ値を返す（int への切り捨てを含む）
- 基準身長と今の身長が同じなら s = 1
- 補正しない条件（基準身長 0・未設定、身長 0）では s = 1
- 補間:
  - w = 0 で A の補正、w = 1 で B の補正に一致する
  - A・B の片方が補正なしでもつながる
  - 全員の倍率が 1 なら、w によらず `y' = y`
  - `Unblend(Blend(y)) == y`（w が 0〜1 の途中でも）
- XML:
  - 基準身長が空なら `<CameraHeightBases>` を書き出さない
  - 保存と読込でスロットごとの基準身長が保たれる
  - 要素の無い XML は基準身長が空で読む
  - 身長補正のキーが保存と読込で保たれる

**実機テスト**（devbridge）

- メイド 2 人のタイムラインで、カットごとに基準メイドを切り替え、片方だけ身長を変えても、それぞれのカットの注視点がそのメイドに合う
- 補間区間の途中で、注視点が A と B の補正の間をなめらかに動く
- 補正 ON で別のメイドでキーを打ち、元のメイドで再生しても構図が崩れない
- 新旧両方のボディで、計算した身長がプロフィール表示と一致する
- 着替え（ボディ再ロード）中にカメラが跳ねない
