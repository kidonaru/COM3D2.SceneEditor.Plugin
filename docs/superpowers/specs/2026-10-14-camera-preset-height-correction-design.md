# カメラ・シーンプリセットの身長補正 設計

## 目的

カメラプリセットとシーンプリセットに、カメラの身長補正（基準メイド・基準身長）を保存・適用できるようにする。あわせて、カメラウィンドウで追従と身長補正を変えたときに編集モードへ入らず、履歴にも載らない不具合を直す。

身長補正の設定（基準メイド・基準身長）は、手ブレ（`CameraShakeManager`）と同じく、タイムラインから独立したシーンのライブ値として持つ。

成功の条件:

- 背の高いメイドで保存したプリセットを背の低いメイドで読むと、注視点の高さがメイドに合う（タイムライン再生時の身長補正と同じ式）
- 同じメイドで読み直すと、保存時と同じ構図になる
- カメラプリセット・シーンプリセットを読み込むと、身長補正の基準メイドの選択も戻る。続けてキーを打てば身長補正のキーになる
- タイムラインを読み込んでいないときも、カメラウィンドウで身長補正を設定でき、プリセットに保存できる
- タイムラインに設定済みの基準身長は、タイムライン読込中のプリセット適用で上書きされない
- 身長補正を持たない旧プリセットは、従来どおりの構図で読める
- カメラウィンドウで追従・身長補正を変えると編集モードへ入る。タイムライン未読込のときは追従と基準メイドを Undo/Redo できる

## 改訂の経緯

初版ではタイムライン（`TimelineData.cameraHeightBases` と、タイムラインの切り替えで消える `CameraHeightState`）に設定を持たせたままにしていた。シーンプリセットは適用前に必ずタイムラインをアンロードする（`ScenePresetManager.UnloadTimelineForPresetLoad`）ため、基準メイドを戻す先が無かった。手ブレと同じく、タイムラインから独立したマネージャに設定を持たせる形へ改めた。

## 前提（既存の身長補正）

`docs/superpowers/specs/2026-10-12-camera-height-correction-design.md` の仕様を前提にする。要点:

- 補正は追従なしのカメラの注視点の Y だけにかかる。メイドのルートの高さを中心に、`CameraHeightCorrection.CalcScale(基準身長, 今の身長)` 倍する
- 基準身長が未設定（0 以下）・メイドがいない・基準メイドなしでは倍率 1
- カメラキーには基準身長の空間の値を記録する（キーを打つとき逆補正する）

本設計で次の 2 点を変える:

- 基準メイドのライブ値は、タイムラインの新規作成・読込・アンロードで「なし」に戻さない（キーで当たっている値の記録 `appliedSlotNo` と補間の状態だけ戻す）
- 基準身長の保存先は `CameraHeightManager` の 1 か所にする。タイムライン XML の `<CameraHeightBases>` は入出力のためだけに使う

## 仕様

### `CameraHeightManager`（新規）

`CameraShakeManager` と同じく `ManagerBase` の派生で、プラグインに登録する。持つもの:

| メンバー | 内容 |
|---|---|
| `state` | 基準メイドのライブ値と補間の状態（既存の `CameraHeightState`。シングルトンをやめ、マネージャが 1 つ持つ） |
| `bases` | 基準身長（スロット → cm）。`CameraHeightBases`（Unity 非依存の新規クラス）。`Get` / `Set`（0 以下は無視）/ `SetIfUnset` |
| 補正 API | スロット 1 人分の倍率（基準身長を渡す版・`bases` の値を使う版）、今の身長、再生用の補間込みの補正・逆補正 |

`CameraTimelineLayer` の `GetSlotScale` / `GetSlotHeight` / `CorrectTargetPos` / `UncorrectTargetPos` はマネージャへ移し、カメラレイヤーとプリセット（`CameraSnapshot`）が同じ API を使う。

### タイムラインとの関係

| 操作 | 基準メイド（`state`） | 基準身長（`bases`） |
|---|---|---|
| 新規作成 | 今の選択を引き継ぐ。`appliedSlotNo` と補間だけ戻す | そのまま。タイムラインはマネージャの `bases` を共有する |
| ファイル読込 | 同上 | XML の値でスロットごとに上書きする（作者の基準を優先）。XML に無いスロットは残す。以後タイムラインはマネージャの `bases` を共有する |
| アンロード | 同上 | そのまま残る |
| Undo/Redo（`UpdateTimeline`） | 触らない | 触らない（再構築したタイムラインにマネージャの `bases` を共有させ直す） |
| 保存 | — | マネージャの `bases` を全スロット書き出す |

- `TimelineData.cameraHeightBases` は `CameraHeightBases` 型にし、`TimelineManager` が新規作成・読込・Undo 再構築のたびにマネージャのインスタンスを差し込む。`TimelineData` 単体（テスト・XML 往復）では自前のインスタンスで動く
- `TimelineXmlDiff` は従来どおり基準身長を比較から外す
- 基準メイドを選んだままタイムラインを読み込みキーを打つと、身長補正のキーが書かれ、そのタイムラインは MTE で開けなくなる（手ブレと同じ。ユーザー合意済み）
- 保存したタイムラインには、そのタイムラインで使っていないスロットの基準身長も入る（MTE は要素を読み飛ばす。ユーザー合意済み）
- マネージャの値はゲームを再起動すると消える（Config に保存しない）。シーン移動では消さない

### カメラウィンドウ・Inspector の身長補正の行

- タイムラインの有無に関係なく表示し、マネージャを編集する
- 補正そのもの（注視点の Y を変える処理）は、今と同じくタイムライン再生時とプリセット適用時だけにかかる

### 保存するデータ（プリセット）

`ScenePresetCamera` に 2 つの属性を足す。

| 名前 | 型 | 既定 | 内容 |
|---|---|---|---|
| `heightSlotNo` | int | -1（補正なし） | 身長補正の基準メイドのスロット番号 |
| `heightBase` | int | 0（未設定） | そのスロットの基準身長（cm） |

- 追従していないとき（`maidSlotNo < 0`）の `targetPos` は、基準身長の空間の値（補正前の値）として持つ。追従中は従来どおり追従点からのオフセットで、身長補正はかけない
- シーンプリセットは **v43** に上げる。属性の無い旧プリセットは `heightSlotNo = -1` で読む
- カメラプリセットの文字列は 19 値から **21 値**にし、末尾に `heightSlotNo,heightBase` を足す。8 / 11 / 19 値の旧形式は身長補正なしで読む
- SceneCapture プリセットからの変換結果は身長補正なし

### 保存（`CameraSnapshot.CaptureState`）

- タイムラインの有無に関係なく、`heightSlotNo` にマネージャの基準メイド、`heightBase` にそのスロットの基準身長を入れる
- 追従していなければ、注視点の Y をそのスロット 1 人分の倍率で逆補正して記録する
  - 再生中にキーとキーの間（2 人の補間中）で保存した場合も、基準メイド 1 人分の倍率で逆補正する。プリセットは補間を持たないため、こうすれば同じメイドで読んだときに画面どおりの位置へ戻る
  - 倍率 1 の条件（基準身長が未設定・メイドがいない）では Y をそのまま記録する

### 適用（`CameraSnapshot.ApplyState` / `ApplyHeight`）

- 追従しておらず `heightSlotNo >= 0` なら、注視点の Y を `CameraHeightCorrection.Correct(y, ルートの高さ, CalcScale(heightBase, 今の身長))` で補正してから置く
  - 補正に使う基準身長は、マネージャの値ではなくプリセットの `heightBase`。同じメイドなら保存時と同じ構図になる
  - スロットにメイドがいない、または `heightBase` が 0 以下なら補正しない
- 設定の復元:
  - 基準メイドのライブ値を `heightSlotNo` にそろえる（`state.SetLive`）
  - `heightBase > 0` でスロットにメイドがいれば、基準身長を入れる。プリセットの適用でタイムライン未読込なら上書き（シーンの状態の復元）、タイムライン読込中なら未設定のときだけ（作者の基準を守る）。履歴の Undo/Redo では常に未設定のときだけ（基準身長は Undo の対象外で、上書きすると手入力した値が無関係な Undo で戻る）。メイドのいないスロットに入れると、後でそのスロットにメイドを呼んでも「設定済み」で取り込まれなくなるため入れない
- プリセットは追従と同じく、その時点の状態をそのまま再現するものとして扱う。身長補正を持たない旧プリセットを適用すると、基準メイドは「なし」になる

### シーンプリセットの適用タイミング

シーンプリセットは、メイドの呼び出しが終わる前にカメラを適用する（`ApplyScenery`、自動ロードの先出し `PreloadAutoLoadScenery` を含む）。この時点ではメイドのルートの位置や身長が定まっていない。

- `ApplyScenery` では補正をかけずに注視点を置き、身長補正の設定も戻さない
- 全メイドの読み込みが終わった後の `FinishApply` の末尾で、カメラを適用する設定（`ShouldApplyCamera`）なら設定の復元と補正を 1 回行う（`CameraSnapshot.ApplyHeight`）。マネージャはタイムラインのアンロードで消えないため、基準メイドの選択が残る

カメラプリセットの読込と Undo/Redo は、その場で補正まで行う。

### 履歴

- タイムラインを読み込んでいる間、`HistoryManager` はシーン操作の snapshot を積まない（`isTimelineMode`。Undo はタイムライン側の差分で行う）。タイムラインの Undo/Redo では基準メイドのライブ値を戻さない既存方針のまま
- タイムライン未読込のときは、snapshot 経由で追従と基準メイドを Undo/Redo できる
- 履歴の比較（`Approximately`）に `heightSlotNo` を含める。タイムラインモードでも確定の通知は `before` と `after` の差で決まり、自動キーフレーム登録がこれを頼りにするため、基準メイドの変更を変化として扱わせる。`heightBase` は基準身長を履歴の対象外にする既存方針に合わせて比較しない

### カメラウィンドウの不具合修正

メインカメラタブで、次の操作が編集モードへ入らず、履歴にも記録されていない。

| 操作 | 修正 |
|---|---|
| 追従メイド・追従ポイント・向き反映 | `MaidFollowRowDrawer.Draw` に `onBeforeChange` を渡し、`RecordCameraEdit("追従")` を呼ぶ |
| 追従中のオフセット・ヨーオフセット | 書き込み前に `RecordCameraEdit` を呼ぶ |
| 身長補正の基準メイド | 選択時に `RecordCameraEdit("身長補正")` を呼ぶ |
| 基準身長の入力・「取得」 | 履歴の対象外のまま、書き込み前に `AutoEditMode.Enter()` だけを呼ぶ |

`MainCameraRowDrawer` の「追従設定は履歴対象外」というコメントは、`CameraSnapshot` が追従を含むようになった時点で古くなっているので直す。

## 互換

- シーンプリセット v43 を旧 SE で読むと `heightSlotNo` / `heightBase` は読み飛ばされ、注視点は基準身長の空間の値のまま置かれる（基準身長と今の身長が違えば高さがずれる）
- 21 値のカメラプリセットを旧 SE で読むと値数が合わず読めない（既存の「新しい版で保存したプリセットを古い版で読む」エラーと同じ扱い）
- タイムライン XML の形式は変えない（`<CameraHeightBases>` に使っていないスロットが入りうるだけ）
- CLAUDE.md の互換性の節に v43 と、読込時に基準メイドを戻さなくなったことの追記を入れる

## テスト

- `CameraPresetStringTests`: 21 値の往復、19 値以下の旧形式は `heightSlotNo = -1`
- 保存時の逆補正と適用時の補正の往復で Y が戻ること（`CameraHeightCorrection` の純粋関数で確かめる）
- `CameraHeightBases`: 0 以下を無視、`SetIfUnset`、スロットごとの上書き取り込み
- `CameraHeightState`: タイムライン切替のリセットでライブ値が残り、`appliedSlotNo` と補間が戻る
- 既存の `CameraHeightBaseTests`（`TimelineData` の XML 往復）が通ること
- 実機確認: タイムライン未読込での設定・保存、シーンプリセット（`LoadPreset` 経由）で基準メイドが戻る、タイムラインの新規作成・読込・アンロード・Undo での引き継ぎ、カメラプリセット、カメラウィンドウでの編集モードへの切り替え
