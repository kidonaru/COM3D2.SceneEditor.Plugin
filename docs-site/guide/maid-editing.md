# メイド編集

## メイド関連ウィンドウ

メニューバー `メイド` から以下のウィンドウを開けます。

| ウィンドウ | 内容 |
|---|---|
| 呼出 | メイドの呼出・配置。メイド行の「選択」ボタンで操作対象を切替 |
| モーション | モーション（ポーズ）の適用 |
| 表情 | 表情の編集・プリセット |
| 指 | 指ポーズの編集・プリセット |
| IK | IK 固定・視線などの制御 |
| 脱衣 | スロット単位の脱衣 |
| 重力 | 髪・スカートの重力制御（`髪` / `スカート` のタブで切替） |
| ボーン | 装着アイテム・配置モデルのボーン編集・プリセット |

呼出ウィンドウの `配置` では、複数人を呼び出したときの並べ方を `V字` / `横一列` から選べます。
メイド行の「選択」ボタンで操作対象を切り替えると、SceneView もそのメイドへフォーカスします。

## 編集モード

`Tab`（またはメニューバーの `編集モード` トグル）で編集モードを切り替えると、
メイドにドラッグ点とギズモが表示され、直接ポーズを付けられます。

| 操作 | 内容 |
|---|---|
| SceneView / GameView でドラッグ点をドラッグ | 手足・肘膝・肩・胸の IK、顔向き、上体・骨盤の操作 |
| 上記 + `Ctrl` | 肘膝の固定・ひねり操作に切り替え |
| SceneView / GameView でドラッグ点をクリック | 対応する IK / ボーンを Inspector に表示 |
| `Alt` + `Ctrl` + 頭のドラッグ点をドラッグ | 瞳の向きの操作 |
| `Alt` | 手首 / 足首 / 頭の回転ギズモを表示 |
| `Alt` + `Ctrl` | 肘 / 膝の回転ギズモを表示 |
| `Alt` + `Shift` | 肩 / 腿 / 鎖骨の回転ギズモを表示 |
| ボーン表示中に関節をクリック | 編集するボーンの選択（ギズモがそのボーンへ付く） |

`メイド` → `指` の指ウィンドウでは、`手指` / `足指` タブのスライダー（`開き` / `閉じ`）で
片手・片足ごとのブレンドを調整できます。
`ロック` 行の指ボタンを押した指は、スライダーを動かしてもロック時点の形を保ちます。

スライダーの値とロック状態はメイドごとに保持されるため、対象メイドを切り替えても元の状態に戻ります。

| 操作 | 内容 |
|---|---|
| `指を保存` | 現在の指の形を指プリセットとして保存 |
| `個別編集` | 指関節ごとのドラッグ点の表示切替 |
| `リセット` | 手指・足指すべてを初期状態へ戻す |
| `更新` | モーション再生でポーズが上書きされた後、スライダー値を再適用 |
| `左手にコピー` / `右手にコピー` | 反対側の手（足）へ同じ形をコピー |
| 部位行右端のフォーカスボタン | SceneView のカメラをその部位の指へ寄せる |

### 個別編集

`個別編集` を ON にすると、指の各関節と指先にドラッグ点が表示され、1 関節ずつ形を作れます
（体のドラッグ点と同じくボーン表示中のみ表示されます）。

| 操作 | 内容 |
|---|---|
| 関節のドラッグ点を上下ドラッグ | その関節の曲げ |
| 指先のドラッグ点を上下ドラッグ | 指 1 本を丸ごとカール |
| 根本関節 / 指先のドラッグ点を左右ドラッグ | 指の開き（スプレッド） |

可動域は指ブレンドのテンプレートから関節ごとに算出しているため、逆反りや一回転はしません。

### 指プリセット

`プリセット` タブに保存済みの指プリセットが並び、押すと即適用されます。
`適用部位` のトグルで、適用する部位（右手 / 左手 / 右足 / 左足）を絞れます。

個別編集で付けた関節の回転もプリセットに保存されます。
回転を持たない従来のプリセットもそのまま読み込めます。

## モーションとポーズ

`メイド` → `モーション` でモーションウィンドウを開きます。
`カテゴリ` でスタジオモードと同じカテゴリを切り替え、一覧のエントリを押すと即適用されます。
`マイポーズ` カテゴリには保存済みのポーズが並び、フォルダ分けにも対応しています。

マイポーズも通常のモーションと同じアニメーションとして再生されるため、
一度読み込んだポーズをそのまま再生・シークできます。

| 操作 | 内容 |
|---|---|
| `再生中` の `<` / `>` | 再生中エントリが属する一覧の前後へ送る（一覧を開かずに切り替えられます） |
| `▶` / `■` | 再生 / 停止。停止は現在のフレームで止まります |
| `再生位置` | 再生位置のシーク。動かすと即座にそのフレームへ移り、停止中はそのフレームのポーズになります |
| `ポーズ保存` | 現在のポーズをマイポーズとして保存 |
| `開く` | マイポーズの保存先フォルダをエクスプローラーで開く |
| `リセット` | ドラッグ点などで崩したポーズを、停止した時点のポーズへ戻します（停止中のみ操作できます） |

`リセット` の戻り先は、シーンプリセットからポーズを復元した場合は復元したポーズになります。

ポーズはゲーム標準のマイポーズと共通の `PhotoModeData\MyPose\` に保存されます。

## ボーン編集

`メイド` → `ボーン` でボーン編集ウィンドウを開きます。
`メイド` / `モデル` の対象タブで、装着アイテムのボーンと外部プラグインが配置したモデルのボーンを
切り替えて編集できます。

| 対象タブ | 編集対象 | 対象の選び方 |
|---|---|---|
| メイド | 選択中メイドの装着アイテム（スロット単位） | `スロット` のリストから選択（編集済みのスロットには `*` が付きます。`なし` を選ぶと骨格線が消えます） |
| モデル | 連携プラグインが配置したモデル | `対象` のリストから選択 |

`ボーン表示` を ON にするとボーンが可視化され、ツリーの行や SceneView 上の関節をクリックして
編集するボーンを選べます。選んだボーンは Inspector の `位置` / `回転` / `拡縮` の行やギズモで編集します。
表示・編集する座標系はギズモの Local / Global 切替に追従します。
ボーン名の行右端のフォーカスボタンで、SceneView のカメラをそのボーンへ寄せられます。

### モデルのボーン編集

`モデル` タブの一覧には、連携 API（ModelProviderHost）に対応した外部プラグインが配置したモデルが並びます。
対応プラグインを導入していない場合は「対応プラグインの配置モデルがありません」と表示されます。

現在は [COM3D2.ModItemExplorer.Plugin](https://github.com/kidonaru/COM3D2.ModItemExplorer.Plugin/releases)
v2.0.0.0 以降が対応しています（[インストール](/guide/installation#推奨プラグイン-連携対応)も参照）。

`対象` の選択は SceneView での選択と双方向に連動します。

- SceneView でモデルをクリックすると `対象` が切り替わります
- `対象` を変えると SceneView の選択もそのモデルへ移ります
- 設定 `linkExternalPlugin` が ON の場合は、対応プラグイン側の選択とも連動します

モデルの編集差分はシーンプリセットにも保存され、読み込み時にそのまま再現されます
（モデル自体の復元には配置元のプラグインが必要です）。
このボーン編集差分の復元は「読込:」トグルの対象外で、対象のモデルが存在すれば適用されます。

### ボーンプリセット

`プリセット` タブから、PartsEditWithStudio 互換のプリセットを保存・適用できます。

- 保存先は PartsEditWithStudio と共用の `Sybaris\UnityInjector\Config\PartsEdit\*.xml` で、
  PartsEdit で保存した既存プリセットもそのまま読めます
- 一覧は対象種別（メイド用 / モデル用）で自動的に絞り込まれます
- 保存はウィンドウ上部の `プリセット保存` ボタンから行います（どのタブからでも押せます）
- 検索欄で名前による絞り込みができます

### 注意

メイドのボーン編集の差分は着替えを検出すると破棄されます
（同じ衣装のままならロード完了後に再適用されます）。

揺れものが付いたボーンを Inspector やギズモから編集すると、編集した回転が毎フレーム上書きされないよう
そのボーンの揺れものが自動的に OFF になります（Inspector の `揺れもの` から戻せます）。
