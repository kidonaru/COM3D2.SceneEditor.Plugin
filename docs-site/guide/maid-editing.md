# メイド編集

## メイド関連ウィンドウ

メニューバー `メイド` から以下のウィンドウを開けます。

| ウィンドウ | 内容 |
|---|---|
| 呼出 | メイドの呼出・配置。メイド行の「選択」ボタンで操作対象を切替 |
| モーション | モーション（ポーズ）の適用 |
| 表情 | 表情・視線の編集とプリセット（`目` / `眉` / `口` / `オプション` / `視線` / `プリセット` のタブで切替） |
| 指 | 指ポーズの編集・プリセット |
| IK | IK 固定と IK アニメーションの制御 |
| 脱衣 | スロット単位の脱衣 |
| 重力 | 髪・スカートの重力制御（`髪` / `スカート` のタブで切替） |
| ボーン | 装着アイテム・配置モデルのボーン編集・プリセット |
| シェイプキー | メイド・配置モデルのシェイプキー編集 |
| マテリアル | メイド・配置モデル・背景のマテリアル編集 |

呼出ウィンドウの `配置` では、複数人を呼び出したときの並べ方を `V字` / `横一列` から選べます。
メイド行の「選択」ボタンで操作対象を切り替えると、SceneView もそのメイドへフォーカスします。

## 編集モード

`F1`（またはメニューバーの `編集モード` トグル）で編集モードを切り替えると、
GameView にもメイドのドラッグ点とギズモが表示され、直接ポーズを付けられます。

SceneView では編集モードに関係なく表示され、掴むと自動的に編集モードへ入ります。
表示の条件はビューごとに異なります。

| 表示するもの | 表示される条件 |
|---|---|
| SceneView のドラッグ点 | `ボーン表示` トグルが ON |
| SceneView のギズモ | SceneView ツールバーの `ギズモ` が ON |
| GameView のドラッグ点とギズモ | 編集モード中で `ボーン表示` トグルが ON |
| 骨格線・ボーン回転ギズモ・指のドラッグ点 | どちらのビューでも、編集モード中で `ボーン表示` トグルが ON |

`ボーン表示` トグルは既定で ON です。

編集モード中のメイドは次の操作で編集できます。

| 操作 | 内容 |
|---|---|
| SceneView / GameView でドラッグ点をドラッグ | 手足・肘膝・肩・胸の IK、顔向き、上体・骨盤の操作 |
| 上記 + `Ctrl` | 肘膝の固定・ひねり操作に切り替え |
| 骨盤のドラッグ点 + `Shift` | 中心（Bip01）の移動。カメラに正対する面に沿って動きます |
| SceneView / GameView でドラッグ点をクリック | 対応する IK / ボーンを Inspector に表示 |
| `Alt` + `Ctrl` + 頭のドラッグ点をドラッグ | 瞳の向きの操作 |
| `Alt` | 手首 / 足首 / 頭 / 中心の回転ギズモを表示 |
| `Alt` + `Ctrl` | 肘 / 膝の回転ギズモを表示 |
| `Alt` + `Shift` | 肩 / 腿 / 鎖骨の回転ギズモを表示 |
| ボーン表示中に関節をクリック | 編集するボーンの選択（ギズモがそのボーンへ付く） |

## 視線

表情ウィンドウの `視線` タブで、顔と瞳の向きを編集します。
項目によって書き込み先が違います。

| 項目 | 書き込み先 |
|---|---|
| `向け先` / `顔向き左右` / `顔向き上下` / `瞳位置` | `メイド瞳` レイヤーのキーフレーム |
| `メイド目線` | タイムライン全体の設定（キーフレームではありません） |

`メイド目線` と `向け先` はタイムラインを読み込んでいないと編集できず、
`タイムライン未読込のため視線は編集できません` と表示されます。
`瞳位置` は読み込んでいなくても編集できますが、キーフレームには残りません。

タイムラインを読み込んでいて `メイド瞳` レイヤーが無いときは、
タブ全体が操作できなくなり、上部に追加ボタンが出ます
（[レイヤーゲート](/timeline/layers#レイヤーゲート)）。

### メイド目線

顔と瞳をカメラや注視先へどう向けるかをまとめて決めます。
メイドごとではなく**タイムライン全体の設定**なので、複数人を呼び出していても 1 つです。

| 目線種別 | 顔 | 瞳 |
|---|---|---|
| `無し` / `無視する` | 動かさない | 動かさない |
| `顔を向ける` / `目と顔を向ける` | 向ける | 向ける |
| `顔だけ動かす` | 向ける | 動かさない |
| `顔をそらす` | 向ける | そらす |
| `目だけ向ける` | 動かさない | 向ける |
| `目だけそらす` | 動かさない | そらす |

`無し` を選ぶとタイムラインは視線を動かしません。

`そらす` 系は注視先を置かない状態でだけ働く演出です。
カメラを見つめすぎると注視点が周期的にカメラから外れた位置へ移り、顔も瞳もその点を追います。

ドラッグ点で頭や瞳を操作すると追従は自動的に切れます。
そのままでは戻らないので、`メイド目線` を選び直すか、タイムラインを再生してください。

### 向け先

誰を・何を見るかを選びます。

| 向け先 | 内容 |
|---|---|
| `カメラ` | メインカメラを見ます |
| `マウス` | マウスカーソルの位置を見ます |
| `メイド` | 呼び出し済みの別のメイドを見ます |
| `モデル` | 配置モデルを見ます |
| `方向指定` | 注視先を置かず、`顔向き左右` / `顔向き上下` で向きを直接決めます |

対象の選び方:

- `メイド` を選ぶと `メイド`（対象）と `ポイント`（`顔` / `胸` / `股` / `尻` / `中心`）の行が出ます
- `モデル` を選ぶと `モデル`（対象）の行が出ます
- `顔向き左右` / `顔向き上下`（値域 -1〜1）は `方向指定` のときだけ操作できます

注意:

- 向け先を切り替えると対象の選択は `未選択` に戻ります。別の対象へ注視が飛ばないようにするためです
- `メイド` / `モデル` で対象が `未選択` のままのときは、注視先が無い扱いになります。
  `メイド目線` が `そらす` 系でなければ `方向指定` と同じで、`そらす` 系なら `無し` と同じ（顔向きの値も効かない）になります
- `そらす` 系の `メイド目線` を選んでいるときは `方向指定` の向きが効きません。`カメラ` と `マウス` はそらし中でも優先されます

`タイムライン視線を初期化` を押すと、向け先が `方向指定` に、顔向きが 0 に戻ります。

### 瞳位置

瞳そのものの位置と大きさを、左右それぞれ調整します。
`メイド目線` や `向け先` とは独立していて、どの設定でも効きます。

| 項目 | 入力 |
|---|---|
| `左瞳位置` / `右瞳位置` | `水平` / `垂直` |
| `左瞳サイズ` / `右瞳サイズ` | `幅` / `高さ` |

左上の図は瞳の位置を表していて、ドラッグしても動かせます。
`初期化` ですべて 0 に戻ります。

キーの補間や値の詳しい仕様は[メイド瞳レイヤー](/timeline/layers-maid#メイド瞳)を参照してください。

`メイド` → `指` の指ウィンドウでは、`手指` / `足指` タブのスライダー（`開き` / `閉じ`）で
片手・片足ごとのブレンドを調整できます。
`ロック` 行の指ボタンを押した指は、スライダーを動かしてもロック時点の形を保ちます。

スライダーの値とロック状態はメイドごとに保持されるため、対象メイドを切り替えても元の状態に戻ります。

| 操作 | 内容 |
|---|---|
| `指を保存` | 現在の指の形を指プリセットとして保存 |
| `個別編集` | 指関節ごとのドラッグ点の表示切替 |
| `リセット` | 手指・足指すべてを初期状態へ戻す |
| `更新` | モーション再生でポーズが上書きされた後、スライダー値を再適用 |
| `左手にコピー` / `右手にコピー` | 反対側の手（足）へ同じ形をコピー |
| 部位行右端のフォーカスボタン | SceneView のカメラをその部位の指へ寄せる |

### 個別編集

`個別編集` を ON にすると、指の各関節と指先にドラッグ点が表示され、1 関節ずつ形を作れます
（体のドラッグ点と同じくボーン表示中のみ表示されます）。

| 操作 | 内容 |
|---|---|
| 関節のドラッグ点を上下ドラッグ | その関節の曲げ |
| 指先のドラッグ点を上下ドラッグ | 指 1 本を丸ごとカール |
| 根本関節 / 指先のドラッグ点を左右ドラッグ | 指の開き（スプレッド） |

可動域は指ブレンドのテンプレートから関節ごとに算出しているため、逆反りや一回転はしません。

### 指プリセット

`プリセット` タブに保存済みの指プリセットが並び、押すと即適用されます。
`適用部位` のトグルで、適用する部位（右手 / 左手 / 右足 / 左足）を絞れます。

個別編集で付けた関節の回転もプリセットに保存されます。
回転を持たない従来のプリセットもそのまま読み込めます。

## モーションとポーズ

`メイド` → `モーション` でモーションウィンドウを開きます。
`カテゴリ` でスタジオモードと同じカテゴリを切り替え、一覧のエントリを押すと即適用されます。
`マイポーズ` カテゴリには保存済みのポーズが並び、フォルダ分けにも対応しています。

マイポーズも通常のモーションと同じアニメーションとして再生されるため、
一度読み込んだポーズをそのまま再生・シークできます。

| 操作 | 内容 |
|---|---|
| `検索` | 一覧を名前で絞り込む |
| `再生中` の `<` / `>` | 再生中エントリが属する一覧の前後へ送る（一覧を開かずに切り替えられます） |
| `▶` / `■` | 再生 / 停止。停止は現在のフレームで止まります |
| `再生位置` | 再生位置のシーク。動かすと即座にそのフレームへ移り、停止中はそのフレームのポーズになります |
| `ポーズ保存` | 現在のポーズをマイポーズとして保存 |
| `開く` | マイポーズの保存先フォルダをエクスプローラーで開く |
| `反転` | 現在のポーズを左右反転します |
| `リセット` | ドラッグ点などで崩したポーズを、停止した時点のポーズへ戻します（停止中のみ操作できます） |

`反転` では IK 固定の左右も入れ替わります。
再生中に押した場合は、モーションを停止してから反転します。

`リセット` の戻り先は、シーンプリセットからポーズを復元した場合は復元したポーズになります。

`検索` に入力すると、表示中のカテゴリの一覧を名前で絞り込めます。
マイポーズの検索は、以下の点が他のカテゴリと異なります。

- 表示中のフォルダより下のサブフォルダまで検索対象になります
- 見つかったポーズはフォルダ分けせず、相対パス付きの 1 つの一覧として並びます
- 検索中は下位フォルダへ進むボタンが出ません（親フォルダへ戻る `←` のボタンは検索中も出たままです）

`再生中` の `<` / `>` は絞り込みの影響を受けません。
モーションのカテゴリではカテゴリ全体を、
マイポーズでは再生中のポーズが属するフォルダの中だけを辿ります。

ポーズはゲーム標準のマイポーズと共通の `PhotoModeData\MyPose\` に保存されます。

### アニメブレンド

`アニメブレンド` を開くと、ベースモーションの上に別のモーションやマイポーズを
アニメレイヤー (2〜8) へ重ねて再生できます。

| 項目 | 内容 |
|---|---|
| `適用先` | 一覧クリックの載せ先。`通常` は従来どおりベースモーションを差し替え、`レイヤーN` はそのレイヤーへ重ねます |
| `▶` / `■` | そのレイヤーだけを再生 / 停止します (ベースが停止中は操作できません) |
| `削除` | レイヤーからアニメを外します |
| `再生時間` | レイヤーの再生位置。停止中は即座にそのフレームが混ざります |
| `重み` | 混ぜる割合 (0〜1) |
| `速度` / `ループ` | レイヤーの再生速度 (0〜2) とループ |

ベースを `■` で止めると、重ねたレイヤーもそのフレームで止まり、ボーン編集の基準になります。

載せられないモーション:

- スクリプト経由で再生されるモーション（エディットカテゴリの一部）はレイヤーへ載せられません
- 同じモーションを複数のレイヤーへ同時に重ねると、後から載せた側が有効になり、
  先に載っていたレイヤーは自動的に外れます

タイムラインとの連携:

- タイムライン読込中は「メイドアニメブレンド」レイヤーの範囲として扱われ、値の変更がキーになります
- Mod モーションを載せた状態はタイムライン XML に絶対パスで保存されるため、別環境では再生できません

## ボーン編集

`メイド` → `ボーン` でボーン編集ウィンドウを開きます。
`メイド` / `モデル` の対象タブで、装着アイテムのボーンと外部プラグインが配置したモデルのボーンを
切り替えて編集できます。

| 対象タブ | 編集対象 | 対象の選び方 |
|---|---|---|
| メイド | 選択中メイドの装着アイテム（スロット単位） | `スロット` のリストから選択（編集済みのスロットには `*` が付きます。`なし` を選ぶと骨格線が消えます） |
| モデル | 連携プラグインが配置したモデル | `対象` のリストから選択 |

`ボーン表示` を ON にするとボーンが可視化され、ツリーの行や SceneView 上の関節をクリックして
編集するボーンを選べます。選んだボーンは Inspector の `位置` / `回転` / `拡縮` の行やギズモで編集します。
表示・編集する座標系はギズモの Local / Global 切替に追従します。
ボーン名の行右端のフォーカスボタンで、SceneView のカメラをそのボーンへ寄せられます。

### モデルのボーン編集

`モデル` タブの一覧には、連携 API（ModelProviderHost）に対応した外部プラグインが配置したモデルが並びます。
対応プラグインを導入していない場合は「対応プラグインの配置モデルがありません」と表示されます。

現在は [COM3D2.ModItemExplorer.Plugin](https://github.com/kidonaru/COM3D2.ModItemExplorer.Plugin/releases)
v2.0.0.0 以降が対応しています（[インストール](/guide/installation#推奨プラグイン-連携対応)も参照）。

`対象` の選択は SceneView での選択と双方向に連動します。

- SceneView でモデルをクリックすると `対象` が切り替わります
- `対象` を変えると SceneView の選択もそのモデルへ移ります
- 設定 `linkExternalPlugin` が ON の場合は、対応プラグイン側の選択とも連動します

モデルの編集差分はシーンプリセットにも保存され、読み込み時にそのまま再現されます
（モデル自体の復元には配置元のプラグインが必要です）。
このボーン編集差分の復元は「読込:」トグルの対象外で、対象のモデルが存在すれば適用されます。

### ボーンプリセット

`プリセット` タブから、PartsEditWithStudio 互換のプリセットを保存・適用できます。

- 保存先は PartsEditWithStudio と共用の `Sybaris\UnityInjector\Config\PartsEdit\*.xml` で、
  PartsEdit で保存した既存プリセットもそのまま読めます
- 一覧は対象種別（メイド用 / モデル用）で自動的に絞り込まれます
- 保存はウィンドウ上部の `プリセット保存` ボタンから行います（どのタブからでも押せます）
- 検索欄で名前による絞り込みができます

### 注意

メイドのボーン編集の差分は着替えを検出すると破棄されます
（同じ衣装のままならロード完了後に再適用されます）。

揺れものが付いたボーンを Inspector やギズモから編集すると、編集した回転が毎フレーム上書きされないよう
そのボーンの揺れものが自動的に OFF になります（Inspector の `揺れもの` から戻せます）。
