# 既知の制限

- ゲーム標準の NGUI UI はウィンドウ化されません。モード中は非表示になります。
  確認ダイアログ等も見えなくなるため、その場合は `F10` でモードを解除してください。
- ダンスシーン・VR シーンには対応していません。
- シーン遷移（事務所 → エディット等）を行うとモードは自動的に解除されます。
- `Alt` + `S` の差し替えは VR カメラには適用されず、VR のスナップショットはゲーム標準のままです。
- 3D シーンの描画領域内にカーソルがある間、`Input.mousePosition` の戻り値は
  プロセス全体で RenderTexture 座標へ書き換えられます。
  - 影響: 他プラグインのウィンドウをその領域に重ねると、そのウィンドウのホバー判定やドラッグ量が乱れることがあります
  - 回避策: 重ならない位置に配置すれば影響はありません
- SceneView を開いている間はシーンをもう 1 台のカメラで描画するため、描画負荷が増えます。
  閉じている間はカメラが無効化され、負荷はかかりません。
- ギズモの描画は `Hidden/Internal-Colored` シェーダに依存します。取得できない環境では
  ログにその旨が出力され、ギズモだけが表示されなくなります（選択とカメラ操作は動作します）。
- Hierarchy で大量のノード（メイドのボーン階層など）を展開すると描画負荷が高くなります。
- カメラ操作の有効/無効を同様に制御する他プラグイン（内部的に `MainCamera.SetControl` を
  切り替えるもの）と併用すると、操作の奪い合いが起きる場合があります。
- `Input.mousePosition` の Harmony フックはランタイム依存です。
  - 失敗した場合はログにその旨が出力されます
  - 影響: GameView 内の位置ベース picking（メイドのクリック選択・ギズモ操作）だけが無効になります
  - モード自体はそのまま動作します
- ボーン編集の差分は着替えを検出すると破棄されます（同じ衣装のままならロード完了後に再適用されます）。
