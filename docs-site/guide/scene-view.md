# SceneView / Hierarchy / Inspector

## SceneView

ゲーム本体とは独立した専用カメラの映像で、UnityEditor の SceneView と同じ感覚で
視点を動かし、オブジェクトを選択・移動できます。
選択状態は SceneView・Hierarchy・Inspector で共有されます。

| 操作 | 内容 |
|---|---|
| 右ドラッグ + `WASD` / `QE` | 視点回転 + フライスルー（`Shift` で高速） |
| `Alt` + 左ドラッグ | ピボット周りのオービット |
| 中ドラッグ / ホイール | パン / ズーム |
| 左クリック | オブジェクト選択（ギズモ操作・ドラッグ点が優先） |
| 同じ場所を続けてクリック | 重なっている別のオブジェクトへ順に切り替え |
| `F` | 選択対象へフォーカス |
| ツールバー左上のアイコン | 背景 / メイド / ギズモ の描画切替、平行投影の切替 |
| ツールバー右上の `X` `Y` `Z` | 各軸の + 方向から注視点を見る構図へ切り替え |

::: tip 描画負荷について
SceneView を開いている間はシーンをもう 1 台のカメラで描画するため、描画負荷が増えます。
閉じている間はカメラが無効化され、負荷はかかりません。
:::

## Hierarchy

シーン内の GameObject をツリー表示します。

| 操作 | 内容 |
|---|---|
| 行のクリック | オブジェクト選択（SceneView / Inspector と同期） |
| `↑` / `↓` | 選択行の移動 |
| `→` | 展開（展開済みなら最初の子へ移動） |
| `←` | 折りたたみ（折りたたみ済みなら親へ移動） |
| 検索欄 | 名前による絞り込み |

::: warning
メイドのボーン階層など大量のノードを展開すると描画負荷が高くなります。
:::

## Inspector

選択中のオブジェクトの Transform を編集します。

| 操作 | 内容 |
|---|---|
| 数値入力 | 選択オブジェクトの位置 / 回転 / 拡縮の編集 |
| `X` / `Y` / `Z` ラベルを左右ドラッグ | 値の増減（`Shift` で 0.1 倍の細かさ） |
| `R` ボタン | その行を既定値へ戻す |
| `ギズモ` 行 | 操作種別（なし / 移動 / 回転 / 拡縮）と `Local` / `Global` の切替 |
| ボーン選択中 | 回転オフセットのスライダー、揺れものの ON / OFF |
| メイド選択中 | 操作対象の切替、カメラ追従 |

ギズモの操作種別はショートカット `Z`（移動）/ `X`（回転）/ `C`（拡縮）でも切り替えられます。
