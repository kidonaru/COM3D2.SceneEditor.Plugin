# SceneView / Hierarchy / Inspector

## SceneView

ゲーム本体とは独立した専用カメラの映像で、UnityEditor の SceneView と同じ感覚で
視点を動かし、オブジェクトを選択・移動できます。
選択状態は SceneView・Hierarchy・Inspector で共有されます。

| 操作 | 内容 |
|---|---|
| 右ドラッグ + `WASD` / `QE` | 視点回転 + フライスルー（`Shift` で高速） |
| `Alt` + 左ドラッグ | ピボット周りのオービット |
| 中ドラッグ / ホイール | パン / ズーム |
| 左クリック | オブジェクト選択（ギズモ操作・ドラッグ点が優先） |
| 同じ場所を続けてクリック | 重なっている別のオブジェクトへ順に切り替え |
| `F` | 選択対象へフォーカス |
| ツールバー左上のアイコン | 背景 / メイド / ギズモ の描画切替、平行投影の切替、追従（オートフォーカス）の切替、ギズモの軸空間の切替 |
| ツールバー右上の `X` `Y` `Z` | 各軸の + 方向から注視点を見る構図へ切り替え |

追従（オートフォーカス）を ON にすると、オブジェクトの選択やメイドの呼出・配置に合わせて
SceneView が自動的にその対象へ寄ります。
OFF にしても `F` キーと Inspector のフォーカスボタンによる明示的なフォーカスは効きます。

::: tip 描画負荷について
SceneView を開いている間はシーンをもう 1 台のカメラで描画するため、描画負荷が増えます。
閉じている間はカメラが無効化され、負荷はかかりません。
:::

## Hierarchy

シーン内の GameObject をツリー表示します。

| 操作 | 内容 |
|---|---|
| 行のクリック | オブジェクト選択（SceneView / Inspector と同期） |
| `↑` / `↓` | 選択行の移動 |
| `→` | 展開（展開済みなら最初の子へ移動） |
| `←` | 折りたたみ（折りたたみ済みなら親へ移動） |
| 検索欄 | 名前による絞り込み |

::: warning
メイドのボーン階層など大量のノードを展開すると描画負荷が高くなります。
:::

## Inspector

選択中のオブジェクトの Transform を編集します。

| 操作 | 内容 |
|---|---|
| ヘッダー行 | オブジェクトのアクティブ切替・名前の表示・フォーカスボタン |
| 数値入力 | 選択オブジェクトの位置 / 回転 / 拡縮の編集 |
| `X` / `Y` / `Z` ラベルを左右ドラッグ | 値の増減（`Shift` で 0.1 倍の細かさ） |
| `R` ボタン | その行を既定値へ戻す |
| 拡縮行のリンクボタン | XYZ 連動（1 軸の編集を比率で全軸へ反映） |
| `ギズモ` 行 | 操作種別（なし / 移動 / 回転 / 拡縮）と軸空間（`Local` / `Global`）の切替 |
| `表示対象` 行 | ギズモを出す範囲の切替（詳細は下記） |
| ポーズボーン選択中 | ボーンの切替、回転オフセットのスライダー |
| ボーン編集のボーン選択中 | 位置 / 回転 / 拡縮の行、揺れものの ON / OFF |
| メイド選択中 | 操作対象の切替、カメラ追従 |

ヘッダー行右端のフォーカスボタンを押すと、追従（オートフォーカス）の設定に関わらず
SceneView がそのオブジェクトへ寄ります。

### ギズモの切替行

`ギズモ` 行と `表示対象` 行は Inspector の内容の先頭に常に表示されます。
IK やボーンを選んでいるときも未選択のときも同じ位置にあるため、選択状態を変えずに切り替えられます。
この設定は SceneView と GameView のギズモで共有されます。
軸空間は地球儀アイコンのトグルで切り替えます（点灯 = `Global` / 消灯 = `Local`）。SceneView のツールバー左上にも同じトグルがあります。

| 表示対象 | ギズモを出す範囲 |
|---|---|
| `すべて表示` | 呼出中のメイド全員。選択していないメイドのギズモを掴むと、そのメイドが選択されます |
| `選択中` | 選択中のオブジェクトのみ |

ギズモの操作種別はショートカット `Z`（移動）/ `X`（回転）/ `C`（拡縮）でも切り替えられます。

設定に保存されるかは項目ごとに異なります。

| 項目 | 次回起動時 |
|---|---|
| 操作種別（なし / 移動 / 回転 / 拡縮） | 保存されない（一時的なモードのため） |
| `Local` / `Global` | 前回の状態で開く |
| `表示対象` | 前回の状態で開く |
