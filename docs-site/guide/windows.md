# ウィンドウ管理

## GameView

ゲーム画面そのものを表示するウィンドウです。常に最背面に固定されるため、他のウィンドウが隠れることはありません。

| 操作 | 内容 |
|---|---|
| タイトルバーをドラッグ | ウィンドウの移動 |
| 4 辺・4 隅をドラッグ | リサイズ |
| `□` ボタン | 最大化 / 元のサイズへ戻す |
| `◇` / `◆` ボタン | ロック（移動・リサイズの禁止） |

最大化状態は保存され、次回起動時やプラグインの再有効化時にも復元されます。

### ツールバー

GameView にマウスを乗せると、左上（ヘッダーの直下）にツールバーが出ます。他のウィンドウに覆われている部分では出ません。

| 項目 | 内容 |
|---|---|
| カメラのアイコン | スクリーンショットを撮る（メニューバーの撮影と同じ） |
| 比率 | 表示比率の切り替え（`画面` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `カスタム`） |
| 背景 / メイド / モデル / エフェクト / ギズモのアイコン | ゲーム画面の表示を切り替える（点灯 = 表示） |

- 比率を選ぶと、ゲーム画面の中央をその比率で切り出して表示します。構図用の画面分割グリッドも切り出した範囲を等分します。切り出しの外側はカメラ操作・ドラッグ点の対象外です
- 非表示は通常の表示・スクリーンショット・連番画像出力のすべてに効きます。SceneView とサブカメラには影響しません
- 状態は保存され、次回の起動やエディタの再有効化でも引き継がれます。タイムライン操作ウィンドウの表示トグルと同じ状態です
- `エフェクト` は PostEffects.Plugin のポストエフェクトと、ステージライト・ステージレーザー・サイリウムを隠します。ゲーム本来の Bloom・被写界深度は残ります。ポストエフェクトを止めるには PostEffects.Plugin v2.5.0.0 以降が必要です。OFF でも、タイムラインでポストエフェクトや各ライブ演出のレイヤーを選択している間は、その種類だけ表示されます（タイムラインのウィンドウを閉じていても選択は残ります）
- `ギズモ` はメニューバーの `ボーン表示` と同じ状態です。編集モード中だけ、ギズモ・骨格線・ドラッグ点を表示します
- プリセット・タイムラインのサムネイルには背景・メイド・モデル・ライブ演出が写ります。ポストエフェクトは `エフェクト` が OFF なら掛かりません
- PNG 配置の表示は Inspector の各 PNG の `表示` で切り替えます
- 背景を隠した部分は背景色になります。透過 PNG にするときは背景色のアルファを下げて撮影します
- 最大化中・ウィンドウの一時非表示中は、比率の切り出しとツールバーはありません（画面全体を表示します）

## ウィンドウ共通の操作

| 操作 | 内容 |
|---|---|
| タイトルバーをドラッグ | 移動（画面端・他ウィンドウの辺へスナップ吸着） |
| 4 辺・4 隅をドラッグ | リサイズ |
| `x` ボタン | 閉じる |
| `◇` / `◆` ボタン | ロック（移動・リサイズの禁止） |

## ロック

タイトルバーの `◇` を押すとそのウィンドウがロックされ、ボタンが `◆`（アクセント色）に変わります。
ロック中は移動・リサイズ・ドッキングの操作を受け付けなくなるため、配置を決めたあとの誤操作を防げます。
ロック状態はウィンドウごとに保存され、次回起動時にも復元されます。

## タブドッキング

複数のウィンドウを 1 つのタブグループへまとめられます。

| 操作 | 内容 |
|---|---|
| タイトルバー同士を重ねて離す | タブグループへ統合 |
| タブをヘッダー外へドラッグ | 独立ウィンドウへ分離 |

## レイアウトの保存と適用

メニューバー `その他` → `レイアウト` から、現在のウィンドウ配置に名前を付けて保存し、あとから呼び出せます。
レイアウトは `Sybaris\UnityInjector\Config\SceneEditor\WindowLayout\` に保存されます。

配布物には `デフォルト` と `クラシック` の 2 つのサンプルレイアウトが同梱されています。
