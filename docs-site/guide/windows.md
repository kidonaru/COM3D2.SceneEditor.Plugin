# ウィンドウ管理

## GameView

ゲーム画面そのものを表示するウィンドウです。常に最背面に固定されるため、他のウィンドウが隠れることはありません。

| 操作 | 内容 |
|---|---|
| タイトルバーをドラッグ | ウィンドウの移動 |
| 4 辺・4 隅をドラッグ | リサイズ |
| `□` ボタン | 最大化 / 元のサイズへ戻す |
| `◇` / `◆` ボタン | 隣接ウィンドウとの連結（コネクト） |

## ウィンドウ共通の操作

| 操作 | 内容 |
|---|---|
| タイトルバーをドラッグ | 移動（画面端・他ウィンドウの辺へスナップ吸着） |
| 4 辺・4 隅をドラッグ | リサイズ |
| `x` ボタン | 閉じる |
| `◇` / `◆` ボタン | 隣接ウィンドウとの連結（連結中は群全体が一緒に動く） |

## タブドッキング

複数のウィンドウを 1 つのタブグループへまとめられます。

| 操作 | 内容 |
|---|---|
| タイトルバー同士を重ねて離す | タブグループへ統合 |
| タブをヘッダー外へドラッグ | 独立ウィンドウへ分離 |

## レイアウトの保存と適用

メニューバー `その他` から、現在のウィンドウ配置に名前を付けて保存し、あとから呼び出せます。
レイアウトは `Sybaris\UnityInjector\Config\SceneEditor\WindowLayout\` に保存されます。
