# タイムライン

キーフレームを打ってメイドのモーション・カメラ・ライト・表情を時間軸で編集できるウィンドウです。
MotionTimelineEditor（MTE）のタイムライン機能を SceneEditor の内部ウィンドウとして統合したもので、保存形式も MTE 互換です。

メニューバーの「ウィンドウ > タイムライン」から開きます。

## タイムラインの作成と保存

| 操作 | 内容 |
|---|---|
| ファイル > 新規作成 | 現在のメイドで新しいタイムラインを作成 |
| 読み込みコンボボックス | 保存済みタイムラインを読み込み |
| 保存ボタン | 現在のタイムラインを保存 |
| アニメ名 | タイムライン（および出力する .anm）の名前 |

保存形式は MTE のタイムライン XML と互換です。MTE で作成したタイムラインの読み込み、その逆も可能です。
ただし SceneEditor 未対応レイヤーのデータは読み込み時に破棄されるため、
**SceneEditor で保存し直すと未対応レイヤーのデータは失われます**。MTE でも使うタイムラインは別名で保存してください。

タイムラインはシーンプリセットには含まれません。タイムライン自体の保存機能で個別に管理します。

## レイヤー

タイムラインはレイヤー単位で編集します。レイヤーコンボボックスで切り替えます。

| レイヤー | 内容 |
|---|---|
| メイドアニメ | ボーン・IK・指ブレンド・接地などメイドのモーション全般（メイドごと） |
| メイド瞳 | 瞳の位置・スケール・回転と注視ターゲット（メイドごと） |
| メイドシェイプ | 表情などのシェイプキー（メイドごと） |
| カメラ | カメラの位置・回転・距離・視野角 |
| ライト | メインライトと追加ライトの位置・色・強度など |

Hierarchy でメイドや追加ライトを選択すると、タイムライン側のレイヤー・対象メイドも自動で切り替わります。

## キーフレームの編集

1. 「編集モード」トグル（または `F1`）で編集モードに入る
2. ポーズ編集（IK ドラッグ・ボーン回転・指・顔）やカメラ・ライト操作で状態を作る
3. 「登録」（`Return`）で変更したボーンのみ、「全登録」（`Shift+Return`）で全ボーンをキーフレーム登録

「自動登録」トグルを有効にすると、ドラッグ編集（IK・ボーン回転・指・顔）を離したタイミングで
現在フレームへ自動的にキーフレームが登録されます（既定は無効。スライダーによる編集は対象外）。

| 操作 | 内容 |
|---|---|
| キーフレームをドラッグ | 移動 |
| `Shift` + クリック | 複数選択 |
| `Backspace` | 選択キーフレームの削除 |
| `Ctrl+C` / `Ctrl+V` | コピー / ペースト |
| `Ctrl+Shift+V` | 反転ペースト |

キーフレーム操作は SceneEditor の履歴に統合されており、他の編集と同じ Undo / Redo で戻せます。

## 再生とシーク

| 操作 | 既定キー | 内容 |
|---|---|---|
| 再生 / 停止 | `Space` | 現在のタイムラインを再生 |
| 前 / 次フレーム | `A` / `D` | 1 フレーム移動 |
| 前 / 次キーフレーム | `Ctrl+A` / `Ctrl+D` | キーフレーム単位で移動 |

キーバインドはタイムライン設定で変更できます。

## .anm 出力

「ファイル > アニメ出力」で、タイムラインのモーションを .anm ファイルとして書き出せます。
出力先は `PhotoModeData\MyPose` で、フォトモードのマイポーズや SceneEditor のポーズブラウザからそのまま利用できます。
複数メイドのタイムラインでは、2 人目以降は「アニメ名_スロット番号.anm」として出力されます。

## 制限事項

- MTE 固有のレイヤー（サイリウム・ステージライト・背景モデル・ポストエフェクト等）は未対応です。該当データを含む MTE タイムラインを読み込むと、その部分は破棄されます（保存し直すと失われます）
- 瞳レイヤーの注視ターゲットに「モデル」は指定できません（保存データに含まれる場合、UI 上は手動（None）扱いで表示されます）
- DCM（DanceCameraMotion）連携の出力には対応していません
