# タイムライン

キーフレームを打ってメイドのモーション・表情・カメラ・ライト・モデル・演出を時間軸で編集できる機能です。
MotionTimelineEditor（MTE）のタイムラインを SceneEditor の内部ウィンドウとして統合したもので、MTE で作成したタイムライン XML を読み込めます。

メニューバー `Window` → `タイムライン` と `タイムライン操作` で開きます。

## 基本の流れ

1. メイドを配置し、`タイムライン操作` の `ファイル` → `新規作成` でタイムラインを作る
2. 必要なレイヤーを `+` で追加する
3. `編集モード`（`F1`）でポーズやカメラ、ライトなどを操作する
4. `登録`（`Enter`）でキーフレームを打つ。`自動登録`（既定 OFF）なら各ウィンドウの操作が自動でキーになる
5. `再生`（`Space`）で確認し、`セーブ` で保存する
6. 必要なら `アニメ出力` で .anm を、`連番画像出力` で PNG を書き出す

## 詳しい仕様

タイムラインの仕様は分量が多いため、専用の[タイムラインタブ](/timeline/)にまとめています。

- [タイムラインウィンドウ](/timeline/window) — 画面構成とグリッド操作
- [タイムライン操作ウィンドウ](/timeline/control) — 再生・登録・範囲操作・トグル
- [キーフレーム編集](/timeline/editing) — 編集モード、自動登録、変更追跡、履歴
- [レイヤー](/timeline/layers) — 全レイヤーの一覧と各レイヤーの仕様
- [ファイル管理](/timeline/files) — 保存、読込、.anm 出力、連番画像出力、テンプレート
- [MTE 互換と制限事項](/timeline/compatibility)

::: warning MTE との互換は一方向です
SceneEditor で保存したタイムラインは MTE では開けません。MTE の元データは別名で控えてから開いてください。
:::
