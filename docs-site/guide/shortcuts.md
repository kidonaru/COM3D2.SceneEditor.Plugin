# ショートカット

| キー | 内容 |
|---|---|
| `F10` | モードの ON / OFF |
| `Tab` | 編集モードの ON / OFF |
| `Z` / `X` / `C` | ギズモを移動 / 回転 / 拡縮モードにする |
| `Ctrl` + `Z` / `Ctrl` + `X` | 操作を戻す / 進める |
| `Alt` + `S` | 撮影（プラグイン有効中はゲーム標準の撮影を差し替える） |

## SceneView 内

| キー | 内容 |
|---|---|
| 右ドラッグ + `WASD` / `QE` | 視点回転 + フライスルー（`Shift` で高速） |
| `F` | 選択対象へフォーカス |

## Hierarchy 内

| キー | 内容 |
|---|---|
| `↑` / `↓` | 選択行の移動 |
| `→` | 展開（展開済みなら最初の子へ移動） |
| `←` | 折りたたみ（折りたたみ済みなら親へ移動） |

## キーの変更

`F10` や `Tab` などの割り当ては設定ファイルで変更できます。
詳しくは[設定リファレンスのキー設定](/guide/configuration#キー設定)を参照してください。
