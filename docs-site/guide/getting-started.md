# 基本操作

## モードの起動と終了

| 操作 | 内容 |
|---|---|
| `F10` | エディタウィンドウモードの ON / OFF |
| ギアメニューのアイコン | 同上 |
| メニューバー `その他` → `Editor終了` | モード終了 |

モード中はゲーム標準の NGUI UI が非表示になり、3D シーンが GameView ウィンドウの中に描画されます。
確認ダイアログなどゲーム側の UI を操作したくなったら、`F10` でモードを解除してください。

シーン遷移（事務所 → エディット等）を行うとモードは自動的に解除されます。

## メニューバー

画面上部のメニューバーから各ウィンドウの開閉と全体操作を行います。

| メニュー | 内容 |
|---|---|
| `Window` | ウィンドウの開閉<br>表示: Scene / Hierarchy / Inspector / Camera<br>演出: 背景 / サウンド / ライブ演出 / テキスト / 動画 / 動画プレビュー / ライト / PNG配置<br>タイムライン: タイムライン / タイムライン操作 / タイムライン設定 / タイムラインロード / テンプレート<br>その他: プリセット / 操作履歴 / 設定 |
| `メイド` | 呼出 / モーション / 表情 / 指 / IK / 脱衣 / 重力 / ボーン / シェイプキー / マテリアル の開閉 |
| `その他` | 撮影、Game最大化、ゲームUI表示（最大化中のみ）、レイアウトの適用・保存、About、Editor終了 |
| `編集モード` トグル | ポーズ編集の開始（`F1` と同じ）。GameView のドラッグ点・ギズモはこの間だけ表示されます |
| `ボーン表示` トグル | メイドのドラッグ点と装着アイテムの骨格線の表示 |
| `ウィンドウ表示` トグル | プラグインのウィンドウの一括表示切替。OFF の間は 3D シーンを画面へ直接描画し、ON に戻すと元の表示に戻ります（Game最大化の状態は変わりません） |

メニューを 1 つ開いている間は、他のメニュー名にマウスを重ねるだけでそちらへ切り替わります。

左端の `≡` をドラッグするとメニューバー自体を移動できます。

## 表示の仕組み

3D シーンは画面と同じ解像度・アスペクト比で描画され、GameView の中に縮小表示されます。
ウィンドウの縦横比が画面と違う場合は、上下または左右に背景色の余白（レターボックス）が入ります。
これにより、ウィンドウをどんな形にリサイズしても構図はゲーム本来の見え方から変わりません。

モード中は 3D シーンの描画領域内にカーソルがあるときだけカメラ操作が有効になります。
領域外（レターボックスの余白を含む）でのドラッグではカメラは動きません。

## ウィンドウ配置の保存

各ウィンドウの位置・サイズ・開いていたかどうかは終了時に保存され、次回起動時に復元されます。
画面解像度が変わった場合は、保存時との比率に合わせて配置がスケールされます。
