# 演出と撮影

## Camera ウィンドウ

`対象` で `Main`（ゲーム本体のメインカメラ）/ `SceneView`（SceneView 専用カメラ）/ `サブカメラ` / `手ブレ` を切り替えます。
`Main` と `SceneView` では注視点 / 回転 / 距離 / FOV を編集します。

| ボタン | 対象 | 内容 |
|---|---|---|
| `リセット` | 両方 | エディット画面相当の初期構図へ戻す |
| `SceneViewカメラへ合わせる` | `Main` | SceneView の構図をメインカメラへ写す（SceneView を開いていないと押せません） |
| `メインカメラへ合わせる` | `SceneView` | メインカメラの構図を SceneView カメラへ写す |

SceneView カメラは傾き（ロール）を持たないため、`SceneViewカメラへ合わせる` では
メインカメラのロールも 0 へ戻ります。

カメラ構図はプリセットとして 10 スロットまで保存・呼出できます（`Main` 専用）。
プリセットには手ブレの設定も含まれます（手ブレ対応前に保存したプリセットは揺れなしとして読み込まれます）。

`サブカメラ` タブでは `サブカメラ数` で台数を増減し、選んだサブカメラの構図を編集します。
サブカメラはタイムラインのサブカメラレイヤーと同じものです。

### 手ブレ

`手ブレ` タブでメインカメラに手持ちカメラ風の揺れを加えられます。
構図（注視点・角度・距離・FOV）には書き込まず、カメラの表示位置と角度にだけ揺れを乗せる非破壊の機能です。

| 項目 | 内容 |
|---|---|
| `位置振幅 (m)` の `X` / `Y` / `Z` | カメラ自身から見た揺れ幅（X = 右、Y = 上、Z = 前、0〜0.2） |
| `回転振幅 (度)` の `X` / `Y` / `Z` | 向きの揺れ幅（X = ピッチ、Y = ヨー、Z = ロール、0〜5） |
| `周波数` | 揺れの速さの倍率（0〜5、既定 1）。`0` では揺れません |
| `シード` | 波形を変える値（0〜9999）。`ランダム` ボタンで振り直せます |

- タイムラインを読み込んでいなくても揺れるため、キーを打つ前にプレビューできます
- 値の変更は操作履歴に記録され、`Ctrl` + `Z` で戻せます
- タイムラインにキーを打つと、揺れはカメラレイヤーの `手ブレ` 項目として記録されます
  （[カメラ系レイヤー](/timeline/layers-camera)）
- スクリーンショットと連番画像出力にも同じ揺れが乗ります

## ライブ演出 / テキスト / 動画

メニューバー `Window` の `ライブ演出` / `テキスト` / `動画` から、タイムライン用の演出をウィンドウで直接編集できます。
編集はタイムラインを読み込んでいなくても行え、操作履歴にも記録されます。

| ウィンドウ | 内容 |
|---|---|
| ライブ演出 | `ライト` / `レーザー` / `サイリウム` のタブでステージライト・ステージレーザー・サイリウムを編集 |
| テキスト | 画面に重ねるテキストの内容・位置・書式 |
| 動画 | 動画の読み込みと配置。`動画プレビュー` ウィンドウで再生中の映像を確認できます |

テキスト・動画・ライブ演出のライトとレーザーは、`1` `2` `3` … の番号タブで操作対象を切り替えます。
番号タブの右の `追加` / `削除` で対象の数を増減します。
ライブ演出の各タブには `コピー先` の番号タブがあり、選んだ対象へ設定を写せます。

## 背景 / ライト / サウンド / PNG 配置

メニューバー `Window` から各ウィンドウを開きます。

| ウィンドウ | 内容 |
|---|---|
| 背景 | 背景の切替 |
| ライト | メインライト・追加ライトの編集 |
| サウンド | BGM の再生・切替、ボイス / 効果音の再生 |
| PNG配置 | PNG 画像のシーンへの配置 |

ライトウィンドウは上段の `ライト一覧` と下段の `ライト編集` に分かれています。
`ライト一覧` はライト 1 灯ごとのタブ（`メイン` と追加ライト名）で、押すと編集対象が切り替わります。
`追加` / `削除` で追加ライトを増減します。
`ライト編集` には選択中のライトのパラメータが並びます。同じ内容は Inspector のライト行でも編集できます。

| 操作 | 内容 |
|---|---|
| `コピー` / `ペースト` | ライトのパラメータを別のライトへ写す。メインライトへは回転・色・強度・影だけ反映されます |
| `対象` | 追加ライトが照らす対象を `全て` / `キャラのみ` / `背景のみ` から選択（メインライトにはありません） |

追加ライトは種別を `ポイント` / `スポット` / `平行` から選べます。
種別によって編集できる項目が変わります（`平行` は範囲を持たず、`角度` は `スポット` のみ）。

PNG 配置の画像は `Sybaris\UnityInjector\Config\PngPlacement\` と
`PhotoModeData\Texture\` から読み込まれます。

## 撮影

メニューバー `その他` → 撮影、または `Alt` + `S` でスクリーンショットを撮影します。

- プラグインの UI もゲームの UI も写りません
- 解像度は設定ウィンドウの `撮影` タブで 1〜4 倍から選べます（既定は 2 倍。設定項目 `screenshotScale`）
- 背景の透過に対応しています
- 保存先はゲームフォルダの `ScreenShot\` です

::: info Alt + S の差し替え
プラグイン有効中は、ゲーム標準の `Alt` + `S` 撮影がプラグインの撮影に差し替わります。
VR カメラには適用されず、VR のスナップショットはゲーム標準のままです。
:::

## 操作履歴（Undo / Redo）

主要な操作は履歴に記録され、`Ctrl` + `Z` で戻す、`Ctrl` + `X` で進めるができます。
履歴の一覧はメニューバー `Window` → `操作履歴` で確認できます。
保持数は設定項目 `historyLimit`（既定 20、`0` で無効）で変更できます。

以下のウィンドウでの値変更も記録されます。

- マテリアル編集・シェイプキー編集・サブカメラ・テキスト・サウンドの BGM 設定・動画
- ライトのコピー / ペーストと `対象` の切替、ボーンギズモの操作
- ライブ演出（ステージライト・レーザー・サイリウム）

ボイス / 効果音 / ゲーム BGM の再生操作は記録されません。
