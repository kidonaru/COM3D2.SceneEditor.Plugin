# 演出と撮影

## Camera ウィンドウ

カメラ構図をプリセットとして 10 スロットまで保存・呼出できます。

## 背景 / ライト / BGM / PNG 配置

メニューバー `Window` から各ウィンドウを開きます。

| ウィンドウ | 内容 |
|---|---|
| 背景 | 背景の切替 |
| ライト | メインライト・追加ライトの編集 |
| BGM | BGM の再生・切替 |
| PNG配置 | PNG 画像のシーンへの配置 |

ライトウィンドウは上段の `ライト一覧`（メインライト・追加ライトの選択と追加 / 削除）と、
下段の `ライト編集`（選択中のライトのパラメータ）に分かれています。

追加ライトは種別を `ポイント` / `スポット` / `平行` から選べます。
種別によって編集できる項目が変わります（`平行` は範囲を持たず、`角度` は `スポット` のみ）。

PNG 配置の画像は `Sybaris\UnityInjector\Config\PngPlacement\` と
`PhotoModeData\Texture\` から読み込まれます。

## 撮影

メニューバー `その他` → 撮影、または `Alt` + `S` でスクリーンショットを撮影します。

- プラグインの UI もゲームの UI も写りません
- 解像度は設定ウィンドウの `撮影` タブで 1〜4 倍から選べます（既定は 2 倍。設定項目 `screenshotScale`）
- 背景の透過に対応しています
- 保存先はゲームフォルダの `ScreenShot\` です

::: info Alt + S の差し替え
プラグイン有効中は、ゲーム標準の `Alt` + `S` 撮影がプラグインの撮影に差し替わります。
VR カメラには適用されず、VR のスナップショットはゲーム標準のままです。
:::

## 操作履歴（Undo / Redo）

主要な操作は履歴に記録され、`Ctrl` + `Z` で戻す、`Ctrl` + `X` で進めるができます。
履歴の一覧はメニューバー `Window` → `操作履歴` で確認できます。
保持数は設定項目 `historyLimit`（既定 20、`0` で無効）で変更できます。
