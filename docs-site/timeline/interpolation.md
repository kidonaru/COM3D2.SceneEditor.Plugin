# 補間とカーブエディタ

## 補間の仕組み

キーとキーの間の値は、各キーが持つタンジェント（傾き）で決まります。
値ごとに **In（流入側）** と **Out（流出側）** の 2 本のタンジェントがあり、それぞれ独立に編集できます。

- タンジェントは `1 = 直線（等速）`、`0 = 水平（区間の端でゆっくり）` を基準にした比率で表されます
- 値が変わらない区間ではタンジェントを変えても形は変わりません。この場合、編集 UI は伏せられます
- 編集対象になる「区間」は、選択したキーの**手前**の区間です。前のキーの Out と選択キーの In を組み合わせて編集します。先頭キーは編集対象になりません
- 1 フレーム幅の区間は `1フレーム調整` の設定で補間されないため、タンジェント編集の対象外です

### プリセット

| 名前 | 内容 |
|---|---|
| `EaseInOut` | 両端で減速する S 字 |
| `EaseIn` | 入りは等速、終わりで減速 |
| `EaseOut` | 入りで減速、終わりは等速 |
| `線形補間` | 直線（等速） |
| `自動補間` | 前後のキーから傾きを自動計算 |

新しいキーの既定は `タイムライン設定` → `共通` の `初期補間曲線`（既定 `Smooth` = 自動補間）で決まります。

階段状に切り替えるプリセットはありません。値を瞬間的に切り替えたいときは、1 フレーム間隔でキーを打ち `1フレーム調整` を使います（[再生とシーク](/timeline/playback#1-フレーム調整)）。

### 旧イージングからの変換

MTE や旧バージョンのタイムラインが持っていたイージング種別（`SineIn` / `CubicInOut` など）は、読み込み時にタンジェントへ自動変換されます。
イージング種別を選ぶ UI はありません。変換は近似で、InOut 系はわずかに形が変わることがあります。

## 補間できない値

レイヤーによっては、補間せず区間の開始キーの値で切り替わる値があります（表示フラグ、追従先、ファイル名、背景の種類など）。
各レイヤーのページに「補間されない値」を記載しています。

## カーブエディタ

タイムラインウィンドウ下端の `▲ カーブ` を押すと開きます。開いている間は `▼ カーブ` になります。
開閉状態と高さは設定に保存されます。ボタン右のバーを上下にドラッグすると高さを 80〜400px の範囲で変えられます。

横軸はグリッドと共有され、縦軸は表示中の値の範囲に自動でフィットします。手動のズームやパンはありません。

### 左ツールバー

ボーンメニューの下に表示されます。

| 要素 | 内容 |
|---|---|
| 値種別コンボ | 表示する値の種類。選択中のキーが持つものだけが候補になります。`すべて` / `移動` / `回転` / `拡縮` / `X移動` … と、レイヤー固有の値 |
| `Out` | 編集区間の Out タンジェント。ラベルを左右ドラッグで相対編集、数値欄で直接入力 |
| `In` | 編集区間の In タンジェント。同上 |
| `自動補間` トグル | 選択区間をすべて自動補間にする / 解除する |
| プリセットのサムネイル | クリックで適用（`EaseInOut` / `EaseIn` / `EaseOut` / `線形補間` / `自動補間`） |

複数のキーを選んでいると、値が混在している欄は空欄になりますが、ラベルドラッグによる相対編集は各キーへ個別に加算されます。

### カーブ表示

- アクティブレイヤーで選択中の項目の、コンボで選んだ値がカーブとして描かれます
- 色は X = 赤、Y = 緑、Z = 青、W = 白。レイヤー固有の値は黄 / 橙 / 紫系です
- 同時に表示できるのは 12 チャンネルまで。超えると `表示上限 12 チャンネル` と表示されます
- クォータニオンで保持される回転は、表示用のオイラー角 3 本に置き換えて描かれます。**値は編集できません**が、タンジェントは編集でき、回転の 4 成分すべてへ同じ形で反映されます
- 自動補間の区間は別色（既定は緑）で描かれます

### マウス操作

| 操作 | 内容 |
|---|---|
| キー点を上下にドラッグ | 値の変更（選択中のキーのみ） |
| タンジェントハンドルをドラッグ | 補間形状の変更。Out ハンドルは右側、In ハンドルは左側にだけ動きます |

ハンドルが出るのは、選択キーの手前の区間で、かつ値が変化する区間だけです。
ドラッグ中は即時プレビューされ、離した時点で履歴に 1 件として記録されます。
フレーム位置の移動はカーブエディタでは行えません。グリッド側で操作してください。

## Inspector の補間曲線タブ

キーフレームを選択したときに Inspector に出る `補間曲線` タブでも同じタンジェントを編集できます。
こちらは区間を 0〜1 に正規化した形だけを表示します。実際の値のカーブを見たいときはカーブエディタを使ってください。
詳しくは[キーフレーム詳細](/timeline/inspector#補間曲線タブ)を参照してください。
