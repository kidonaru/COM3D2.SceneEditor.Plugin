# ファイル管理

ファイル操作はすべて `タイムライン操作` ウィンドウから行います。

## 保存先

| 内容 | 場所 |
|---|---|
| タイムライン XML | `PhotoModeData\_Timeline\<格納ディレクトリ名>\<アニメ名>.xml` |
| サムネイル | 上記 XML と同名の `.png` |
| .anm 出力 | `PhotoModeData\MyPose\<アニメ名>.anm`（2 人目以降は `<アニメ名>_<スロット番号>.anm`） |
| 連番画像 | `PhotoModeData\_Image\<アニメ名>\` |
| テンプレート | `Sybaris\UnityInjector\Config\MotionTimelineEditor\Template\<レイヤー名>.xml`（MTE と共用） |
| タイムラインの共通設定 | `Sybaris\UnityInjector\Config\SceneEditor\Timeline.xml` |

タイムラインはシーンプリセットには含まれません。メイド目線と注視先の設定だけがシーンプリセットに保存されます。

## 新規作成

`ファイル` → `新規作成` で、アニメ名 `テスト` の新しいタイムラインを作ります。
メイドが配置されていないと `メイドが配置されていません` と表示されます。
開いているタイムラインの未保存の変更は確認なく破棄されます。

## 保存

`セーブ` ボタンで保存します。保存後に `タイムライン「名前」を保存しました` と表示され、ロード一覧が更新されます。

- `アニメ名` は `タイムライン操作` の欄で、保存先のサブフォルダは `タイムライン設定` → `個別` の `格納ディレクトリ名` で決めます
- アニメ名は空にできず、`\` や `..`、無効な文字は使えません
- サムネイルは、まだ無い場合だけ保存時に自動撮影されます。撮り直すには `タイムライン設定` → `個別` の `サムネイル更新` を押します
- 保存は常に最新形式（version 34）で書き出されます。MTE では読めなくなる点に注意してください（[MTE 互換と制限事項](/timeline/compatibility)）
- 名前を変えて保存するには、`アニメ名` を変えてから `セーブ` します。削除やリネームの専用機能はありません

保存できないときは理由がダイアログに出ます。

| メッセージ | 原因 |
|---|---|
| `アニメ名を入力してください` | アニメ名が空 |
| `メイドを配置してください` | メイドがいない |
| `トラックの範囲が不正です` | トラックの開始 / 終了が範囲外 |

## 読み込み

`ロード` ボタンで `タイムラインロード` ウィンドウを開きます。

| 要素 | 内容 |
|---|---|
| `<` | 1 階層上のフォルダへ |
| フォルダ名 | 現在のフォルダ |
| `開く` | 現在のフォルダをエクスプローラーで開く |
| `更新` | 一覧を作り直す。外部でファイルを増減したときに押します |
| タイル | サムネイルと名前。クリックで読み込み（確認なし）。フォルダのタイルはクリックで移動 |

- サブフォルダに対応しています。並び順はファイルが先、フォルダが後で、それぞれ自然順です
- 読み込むと未保存の変更と操作履歴は破棄され、0 フレームへ移動します
- メイドの人数はチェックされません。対応するメイドがいないレイヤーは何もせず、Inspector に `対象メイドが見つかりません` と表示されます
- 未登録の種類のレイヤーは読み込み時に破棄されます

## アンロード

`ファイル` → `アンロード` でタイムラインを閉じます。`タイムラインをアンロードしますか？ 未保存の変更は失われます` の確認が出ます。
シーン遷移（事務所 → エディットなど）でもタイムラインは自動で破棄されます。

## .anm 出力

`ファイル` → `アニメ出力` で、メイドアニメレイヤーのモーションを .anm として書き出します。

- 出力先は `PhotoModeData\MyPose` で、フォトモードのマイポーズや SceneEditor のモーションウィンドウからそのまま使えます
- 複数メイドの場合、2 人目以降は `アニメ名_スロット番号.anm` になります
- 含まれるのは体ボーン・中心ボーン・拡張ボーンの回転と位置です。IK 固定・接地・指ブレンド・拡縮は含まれません
- `ループアニメーション`（タイムライン設定）が出力する .anm のループ設定になります
- 完了すると `モーション「名前」を生成しました` と表示されます

## 連番画像出力

`ファイル` → `連番画像出力` で、各フレームを PNG として書き出します。`連番画像出力を開始しますか？ 出力中は[Esc]キーで停止できます` の確認が出ます。

- 出力先は `PhotoModeData\_Image\<アニメ名>\` です。**出力前に同名フォルダを中身ごと削除して作り直します**
- フレームレート、`出力名`（既定 `image_{frame:D6}`）、画像サイズ（既定 1920 × 1080）は `タイムライン設定` → `個別` の `連番画像出力設定` で変更します
- アクティブトラックがあるとその範囲だけ出力します
- 画面と同じ縦横比で描いて中央を切り出すため、GameView の見た目と一致します
- `画像出力先を開く` ボタンで出力フォルダを開けます

## テンプレート

`Window` → `テンプレート` で開きます。選択中のキーフレームを名前付きで保存し、あとから現在フレームを起点に貼り付けられる「キーフレームの型」です。
テンプレートはレイヤーの種類ごとに別のファイルに保存されます。

| タブ | 内容 |
|---|---|
| `操作` | カテゴリごとにテンプレートのボタンが並び、クリックで現在フレームへ適用します。末尾の `テンプレ名` 欄と `追加` で、選択中のキーを新しいテンプレートとして保存します |
| `カテゴリ編集` | `カテゴリ名` の追加、改名、`削除`、`↑` / `↓` での並べ替え。`Default` は改名・削除できません |
| `テンプレ編集` | テンプレートの改名と `削除`（確認なし）、`ソート` |

- 保存されるのは、ボーンメニューで選択中の項目のキーフレームです。項目を選んでいないと `ボーンが選択されていません。` と表示されます
- 適用はテンプレート内の最小フレームを現在フレームに合わせて展開し、履歴に `テンプレ適用: 名前` として記録されます
- 変更は自動で保存されます。保存ボタンはありません
- 保存先を MTE と共用しているため、MTE と同時に起動して両方で編集すると片方の変更が失われます
