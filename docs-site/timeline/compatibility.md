# MTE 互換と制限事項

## MTE との互換は一方向です

MotionTimelineEditor（MTE）で作成したタイムライン XML は SceneEditor で読み込めます。
**SceneEditor で保存した XML を MTE で開くことは非対応です。** 次の挙動は仕様であり、不具合ではありません。

- MTE のタイムライン（version 31）を SceneEditor で開いて保存すると version 34 になり、元には戻せません
- ライトの補間トグル（`ライトで色補間を有効化` / `ライトで拡張補間を有効化` / `ライトの互換性モードを有効化`）は廃止され、ライトは常に補間されます。補間 OFF だった旧データは段差を再現するための保持キーが自動挿入され、キー数が増えます
- イージング種別はタンジェントへ変換され、元のイージング値は消えます。InOut 系はわずかに形が変わることがあります
- COM3D2.5 で廃止された値は既定値へ置き換えられます（パラフィンとリムライトの深度系の値など）
- MTE にしかない項目（ポストエフェクトの Extra / Blend、動画の GUI 位置など）は保存時に落ちます。動画設定は構造が変わるため MTE では読めません
- パラフィンは最大 4 本に切り詰められます。5 本目以降のキーデータは XML に残っても無効です
- `メイド表情` の `強制上書き` キーと `メイド重力` レイヤーは SceneEditor 独自です。これらを含む XML は MTE で読み込みに失敗します
- 未使用のレイヤーは保存時に空のレイヤーとして実体化されます

::: tip
MTE のタイムラインを SceneEditor で開く前に、元の XML を別名や別フォルダに控えておくことをおすすめします。
:::

## 未対応の機能

- DCM（DanceCameraMotion）連携の出力（CSV / song XML）には対応していません。メイド表情・効果音・テキストの各レイヤーは再生と編集のみ対応です
- `タイムライン設定` の `アスペクト比` / `ﾚﾀｰﾎﾞｯｸｽ透過度` は画面に反映されません。値は保存されます
- 開始 / 終了のオフセット時間とフェード時間は使われません
- イージング種別を選ぶ UI はありません。補間はタンジェントに一本化されています

## 外部プラグインへの依存

| 機能 | 必要なもの |
|---|---|
| モデル系レイヤー（モデル / モデルボーン / モデルシェイプ / モデルマテリアル） | [ModItemExplorer](https://github.com/kidonaru/COM3D2.ModItemExplorer.Plugin)。未導入だとレイヤーが出ず、モデルを含むタイムラインを読んでもモデルは復元されません |
| ポストエフェクトレイヤー | PostEffects.Plugin。未導入だとレイヤーが登録されません |

## その他の制限

- `メイド衣装` と `メイドマテリアル` はメイド単位ではなく、タイムラインに 1 本だけです
- `メイドアニメ` の `指ブレンド` は編集モード中かつ指ウィンドウの `TL:ブレンド有効` が ON のときだけ適用されます
- カメラ・サブカメラは自動登録の対象外です
- ステージライト・レーザー・サイリウムは操作履歴に対応していないため自動登録されません
- サイリウムの `パターン` と `移動回転` は Inspector で編集できません（ライブ演出ウィンドウで編集）
- ポストエフェクトは値ごとの個別補間ができません
- モデル系レイヤーで同じファイルのモデルを複数置いている場合、配置順が変わるとキーの割り当て先がずれることがあります
- タイムライン管理外（外部プラグインが提供する）モデルは変更追跡のチェックが効きません
- `背景モデルマテリアル` は変更追跡（チェック）に対応せず、全マテリアルが対象になります
- 効果音はシークを連打すると多重に再生されることがあります
- テキストの既定フォント `Yu Gothic Bold` が無い環境ではフォントを選び直してください
- PNG 配置の画像は `Sybaris\UnityInjector\Config\PngPlacement\` または `PhotoModeData\Texture\` に置いてください。見つからない画像はスキップされます。MTE 固有の値（アタッチ、APNG など）は保持されますが適用されません
- 新規作成・読み込み直後の最初の操作は Undo できません
- シーン遷移でタイムラインは破棄されます。保存していない内容は失われます
- タイムラインはシーンプリセットに含まれません
