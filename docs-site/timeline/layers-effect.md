# ライト・演出系レイヤー

## ライト

メインライトと追加ライトです。項目はライト名ごとに並び、先頭が常にメインライトです。ライトウィンドウで編集します。

| 値 | 既定 | 補間 |
|---|---|---|
| 位置 / 回転 | — | タンジェント補間 |
| 色 | — | 線形補間 |
| `範囲` | 3 | タンジェント補間 |
| `強度` | 0.95 | タンジェント補間 |
| `角度`（スポットのみ） | 50 | タンジェント補間 |
| `影濃` / `影距` | 0.1 / 0.01 | タンジェント補間 |
| `追従`（メイドのスロット番号） | -1 | なし |
| `対象` | `全て` | なし |
| `表示` | — | なし |

- `対象` は `全て` / `キャラのみ` / `背景のみ` から選び、ライトが照らす対象を絞ります。他プラグインが設定したマスクは判別できず `全て` として扱われます
- メインライトはゲーム側の実体のため、`追従` と `対象` は適用されません
- ライトの追加・削除・コピーに合わせて項目とキーが自動で追従します

::: info 旧タイムラインの補間設定
version 33 以前のタイムラインにあった `ライトで色補間を有効化` / `ライトで拡張補間を有効化` / `ライトの互換性モードを有効化` は廃止され、ライトの色や数値は常に補間されます。
補間 OFF だった旧データは、以前と同じ段差の見え方になるよう、値が変わるキーの 1 フレーム前へ保持キーが自動で挿入されます（キー数が増えます）。
:::

## ステージライト

ライブ会場のムービングスポットライトです。ライブ演出ウィンドウの `ライト` タブで編集します。
個別のライトと、それらを束ねる**コントローラー**（`グループ (N)`）の 2 階層があります。

| 値 | 補間 |
|---|---|
| 位置 / 回転 | タンジェント補間 |
| 色 | 線形補間 |
| `角度` / `範囲` | タンジェント補間 |
| 上記以外の設定値（範囲補正、減衰、ノイズ、中心半径、オフセット範囲、分割、Z テスト、表示） | なし（区間開始値） |

コントローラーは位置・角度・色の最小値と最大値（`最小位置` / `最大位置`、`最小角度` / `最大角度`、`最小色` / `最大色`）を持ち、その範囲に配下のライトを配分します。
ライブ演出ウィンドウの `一括表示設定` / `一括位置設定` / `一括角度設定` / `一括色設定` / `一括ライト情報設定` を ON にした項目が配下へ一括適用されます。
キーフレーム詳細ではこれらのトグルは `一括表示` / `一括位置` / `一括回転` / `一括色` / `一括情報` という名前で表示されます。適用はコントローラー → 個別ライトの順です。

## ステージレーザー

レーザーです。ライブ演出ウィンドウの `レーザー` タブで編集します。構成はステージライトと同じく個別レーザーとコントローラーの 2 階層です。

| 値 | 補間 |
|---|---|
| 回転（コントローラーは位置も） | タンジェント補間 |
| 色1 / 色2 | 線形補間 |
| `強度` / `範囲` / `幅` | タンジェント補間 |
| 上記以外の設定値（減衰、ノイズ、中心半径、オフセット範囲、散乱幅、分割、Z テスト、表示） | なし（区間開始値） |

コントローラーは角度の範囲（`最小角度` / `最大角度`。キーフレーム詳細では `最小RX` 〜 `最大RZ`）と一括トグル（ライブ演出ウィンドウの `一括表示設定` / `一括角度設定` / `一括色設定` / `一括レーザー情報設定`、既定 ON）を持ちます。

## サイリウム

観客席のサイリウム（ペンライト）群です。ライブ演出ウィンドウの `サイリウム` タブで編集します。1 レイヤーで 6 種類の設定を扱います。

| 項目グループ | 内容 |
|---|---|
| `グループ (N)`（コントローラー） | グループ全体の位置・回転・表示 |
| バー設定 | 色 1a〜1c / 2a〜2c、`スケール` / `幅` / `高さ` / `Y` / `半径` / `上部閾値` / `A閾値` |
| 手設定 | `両手間`、バーのオフセット `X` / `Y` / `Z`、`RX` / `RY` / `RZ` |
| `エリア` | 配置（位置・回転、`SX` / `SY`、`席幅` / `列幅`、位置のランダム幅）、重み（本数 `0個` 〜 `3個`、色 `色1` / `色2`、パターン `P0` 〜 `P9`）、`乱数Seed` |
| `パターン` | 位置・回転、`T Count` / `T Range` / `ShiftMin` / `ShiftMax` / `乱数Seed` |
| `移動回転` | 左右それぞれの位置と回転 |

- 位置・回転系は補間されます。乱数 Seed や重みなどの設定系は補間されず、区間開始で切り替わります。Seed をキーで変えると配置・本数・色が一斉に切り替わります
- `パターン` と `移動回転` は Inspector では編集できず、ライブ演出ウィンドウで編集します

ステージライト・レーザー・サイリウムは操作履歴に対応していないため、自動登録の対象外です。`登録` か `Enter` で登録してください。

## ポストエフェクト

被写界深度、パラフィン、距離フォグ、リムライト、ブルーム、GTToneMap を扱います。

::: warning PostEffects.Plugin が必要です
実体は PostEffects.Plugin です。未導入の環境ではこのレイヤーは登録されません。
値の編集と、パラフィン・距離フォグ・リムライトの本数の増減は PostEffects.Plugin のウィンドウで行います。
:::

- パラフィン・距離フォグ・リムライトは**最大 4 本**です（上限は PostEffects.Plugin 側の設定に従います）。5 本目以降のキーデータは無効です
- 値ごとの個別補間はできず、区間の代表タンジェントで全項目をまとめて補間します
- `タイムライン操作` の `ポスプロ同期` が OFF で、かつこのレイヤーがアクティブでないときは、全エフェクトが無効になります

パラフィン・距離フォグ・リムライトが持つ合成率は `通常` / `加算` / `乗算` / `オーバーレイ` / `減算` の 5 つで、それぞれ 0〜2 の値です。

### 被写界深度

- `ﾋﾟﾝﾄ距離` / `焦点距離` / `絞り値` / `ﾌﾞﾗｰｻｲｽﾞ`
- `追従`: ピントを合わせるメイドのスロット番号。補間されません

### パラフィン

- 色: 色 / サブ色
- 配置: `X` / `Y`（中心位置）、`外半径` / `内半径`、`SX` / `SY`（半径の倍率）
- 合成率と `マスク`

### 距離フォグ

- 色: 色 / サブ色
- 深度: `開始深度` / `終了深度` / `指数`
- 合成率

### リムライト

- 光の向き（回転）
- 色: 色 / サブ色
- 効果: `影響` / `幅` / `指数`
- 対象: `マスク`、`顔除外`、`髪に適用`
- 合成率と `ワールド空間`

### ブルーム

- 基本: `強度` / `しきい値` / `ﾌﾞﾗｰ回数` / `ﾌﾞﾗｰ広がり`、しきい値色
- キャラと背景の分離: `ｷｬﾗ背景分離` を ON にしたときのキャラ用の `ｷｬﾗ強度` / `ｷｬﾗしきい値` / `ｷｬﾗ広がり`
- レンズフレア: `ﾌﾚｱｽﾀｲﾙ` / `ﾌﾚｱ強度` / `ﾌﾚｱ彩度` / `ﾌﾚｱしきい値` / `ﾌﾚｱ回転` / `伸縮幅` / `ﾌﾚｱﾌﾞﾗｰ回数`、フレア色

### GTToneMap

| 値 | 内容 |
|---|---|
| `MaxBrightness` | 最大輝度 |
| `Contrast` | コントラスト |
| `LinearStart` | 線形域の開始点 |
| `LinearLength` | 線形域の長さ |
| `BlackTightness` | 暗部の締まり |
| `BlackOffset` | 暗部のオフセット |

キーフレーム詳細にはトーンカーブのグラフが描かれます。
