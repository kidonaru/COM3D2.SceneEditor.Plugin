# 再生とシーク

## 再生・停止

| 操作 | 既定キー | 内容 |
|---|---|---|
| `再生` | `Space` | 現在フレームから再生。最終フレームにいる場合は先頭へ戻ってから再生します |
| `停止`（再生中の同じボタン） | `Space` | その場で一時停止。ポーズや各レイヤーの値は現在フレームのまま残ります |

- 再生を始めると編集モードは解除されます。逆に編集モードに入ると再生は止まります
- 再生中は登録済みのすべてのレイヤー（メイド、カメラ、ライト、モデル、演出、字幕など）が同時に反映されます
- 停止時には、ボーンスライダーの基準ポーズがその時点のポーズに取り直されます

## フレーム移動

| 操作 | 既定キー | 内容 |
|---|---|---|
| `前のフレームへ` / `次のフレームへ` | `A` / `D` | 1 フレーム移動。押しっぱなしで連続移動 |
| `前のキーへ` / `次のキーへ` | `Ctrl` + `A` / `Ctrl` + `D` | キーフレーム単位で移動 |
| `先頭へ` / `最終へ` | — | 0 フレーム / 最終フレームへ |
| `フレーム` 欄 | — | 数値入力、またはラベルをドラッグ |
| フレーム番号バー | — | クリックした位置へシーク。ドラッグで連続移動 |

シークすると再生は止まります。編集モード中にシークした場合、未登録の変更は捨てられ、移動先フレームの値が新しい編集の基準になります。

## フレームレートと最終フレーム

| 項目 | 場所 | 既定値 |
|---|---|---|
| フレームレート | `タイムライン設定` → `個別` → `フレームレート`（`30` / `60` ボタンあり） | 30 |
| 最終フレーム | `タイムライン操作` の `最終フレーム` | 30 |

1 フレームの時間は `1 / フレームレート` 秒です。現在フレームは 0 〜 最終フレームの範囲に収まります。

フレームレートを変えてもキーフレームのフレーム番号は変わりません。同じフレーム番号のまま 1 フレームの時間だけが変わるため、30 → 60 にするとアニメーション全体が 2 倍速になります。尺を保ちたい場合はキーを手で打ち直してください。

## ループ

エディタ上の再生は、最終フレームに達すると常に先頭へ戻ります。
`タイムライン設定` → `個別` の `ループアニメーション`（既定 ON）は、出力する .anm のループ設定に効く項目で、エディタの再生には影響しません。

## 再生速度

`タイムライン操作` の `再生速度` で 0〜2 倍に変更できます。`R` で 1 に戻ります。
速度は BGM のピッチと動画の再生速度にも反映されます。

## トラック

トラックは、1 本のタイムラインの中の再生区間に名前を付けたものです。`タイムライン設定` → `トラック` タブで管理します。

| 要素 | 内容 |
|---|---|
| `追加` | `トラック1`、`トラック2`… の名前で、範囲 0 〜 最終フレームのトラックを追加 |
| 行頭のチェック | アクティブトラックの切り替え。ON にすると再生位置がトラックの開始フレームへ移動 |
| 名前欄 | トラック名 |
| `範囲` | 開始フレーム 〜 終了フレーム |
| `削除` | 確認なく削除 |
| `∧` / `∨` | 並べ替え |

アクティブトラックがあると、次の動作がその範囲に限定されます。

- 再生（範囲内でループ）
- シーク
- 連番画像出力

次のいずれかに当てはまる範囲は不正です。

- 開始が 0 未満
- 終了が最終フレームを超える
- 開始 ≧ 終了 − 1

不正な間は `タイムライン操作` の状態メッセージ欄に `トラックの範囲が不正です` と表示され続け、`セーブ` を押すとダイアログでも警告されます。
グリッドにはアクティブトラックの開始・終了位置が赤い縦線で表示されます。

## BGM / 動画との同期

- BGM はタイムラインの再生・停止・シークに追従し、再生速度はピッチに反映されます。対応形式は .ogg / .wav です
- 動画も同様にシークと速度に追従します
- BGM と動画の設定は[その他のレイヤーと BGM / 動画](/timeline/layers-other#bgm-と動画)を参照してください

## 1 フレーム調整

`タイムライン設定` → `個別` の `1フレーム調整` は、1 フレーム間隔で隣り合うキーの扱いを決めます。

| 値 | 内容 |
|---|---|
| `なし` | 補間する |
| `1F遅らせる`（既定） | 1 フレーム幅の区間を補間せず、値を瞬間的に切り替える。切り替え位置を 1 フレーム遅らせる |
| `1F早める` | 同上。切り替え位置を 1 フレーム早める |

値を瞬間的に切り替えたいときは、1 フレーム間隔でキーを打ってこの設定を使います。

メイドのボーン（モーションレイヤーの体ボーンと拡張ボーン）は .anm のカーブ補間で再生されるため、既定では `1フレーム調整` の対象外で、1 フレーム間隔でも補間されます。

`タイムライン設定` の `1フレーム調整を anm にも適用` を ON にすると、次が変わります。

- ボーンにも `1フレーム調整` の規則が適用される
- 書き出した .anm にもその段差が記録される
- 自動補間の計算とタンジェント表示も、ボーンの 1 フレーム区間をカット扱いにする
