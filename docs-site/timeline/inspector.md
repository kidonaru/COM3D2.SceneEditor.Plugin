# キーフレーム詳細（Inspector）

キーフレームの値は Inspector ウィンドウで編集します。Inspector の表示は次の優先順で切り替わります。

1. ボーン編集モード（ギズモ / ボーンスロットの表示）
2. **キーフレーム詳細** — グリッドでキーフレームを 1 つ以上選択しているとき
3. **項目の現在値** — キー未選択で、ボーンメニューの項目を選択しているとき
4. 通常のオブジェクト表示

キーフレームの選択はオブジェクト選択より優先されます。キー選択を解除すると元の表示に戻ります。

## キーフレーム値と現在値の違い

| 表示 | 編集するもの |
|---|---|
| キーフレーム詳細 | 選択したキーフレームに保存されている値そのもの |
| 項目の現在値 | その項目が担当するシーン上の現在の値（ライトの明るさ、カメラの構図など）。各ウィンドウと同じ行が並びます |

現在値を編集した結果は、自動登録か `登録` を通じてキーフレームになります。
キーフレーム詳細は登録済みのキーを直接書き換えます。

## ヘッダー

| 要素 | 内容 |
|---|---|
| タブ | `値` / `補間曲線` |
| `キーフレーム詳細 (N個選択中)` | 選択数 |
| `一括` トグル | 同じ種類のキーをまとめて編集するモード |
| `すべて折りたたみ` / `すべて展開` | 各キーのブロックを一括開閉 |

各キーのブロックは `▼` / `▶` の開閉記号、`項目名 (F フレーム番号)`、`初期化`、`削除` で構成されます。
表示できるブロック数の上限は設定の `detailTransformCount`（既定 16）で、超えた分は `他 N 個は非表示` と表示されます。

## 値タブ

キーの種類に応じて次の行が並びます。

| 行 | 内容 |
|---|---|
| `位置` | XYZ。ラベルのドラッグは 1px = 0.01 |
| `回転` | XYZ（オイラー角）。ラベルのドラッグは 1px = 1.0 |
| 拡縮 | XYZ。XYZ 連動トグル付き |
| 色 | 色見本と編集ボタン。カラーピッカーで編集します |
| 固有の数値 | スライダー、またはトグル。ラベルの左右ドラッグでも増減できます |
| `表示` | 表示フラグを持つ種類のみ |
| 文字列 | ファイル名やテキスト本文など |

編集は即時反映され、履歴には `キーフレーム編集: 項目名` として記録されます。ドラッグ中はマウスを離すまで 1 件にまとめられます。

## 一括モード

`一括` を ON にすると、同じ種類のキーが `種類名 (N個)` の見出しでまとまり、`位置` / `回転` / `拡縮` / 色 / `表示` をまとめて編集できます。
値が混在している欄は空欄で表示されます。

## 補間曲線タブ

| 要素 | 内容 |
|---|---|
| プレビュー | 選択キーの区間を 0〜1 に正規化した曲線。In / Out のハンドルを直接ドラッグできます |
| 編集対象コンボ | 編集する値の種類（カーブエディタと共有） |
| `OutTangent` / `InTangent` | 数値入力、またはラベルの左右ドラッグ |
| `自動補間` トグル | 自動補間の ON / OFF |
| `プリセット反映` | `EaseInOut` / `EaseIn` / `EaseOut` / `線形補間` / `自動補間` |

補間曲線を持たないキーだけを選んでいると `補間曲線を持つキーフレームが選択されていません` と表示されます。
タンジェントの考え方は[補間とカーブエディタ](/timeline/interpolation)を参照してください。

## 選択の連動

- ボーンメニューで項目を選ぶと、Inspector 側のボーン / IK 選択は解除され、その項目の現在値が表示されます
- Hierarchy などでオブジェクトを選ぶと、対応する項目がボーンメニューで選択されます。対応するのはシーン上に実体を持つレイヤー（背景、背景モデル、モデル、モデルボーン、ライト、メイド移動、PNG 配置、メイドアニメのボーン）です

## レイヤーごとの現在値 UI

| レイヤー | 現在値として表示されるもの |
|---|---|
| メイドアニメ | ボーンのスライダー |
| メイドアニメブレンド | 各段のアニメ名・重み・速度・ループ |
| メイド表情 | 表情モーフのスライダーと強制上書きトグル |
| メイド移動 | メイドの位置・回転・拡縮 |
| メイド瞳 | 向け先、注視先、顔向き、瞳の位置・サイズ |
| メイドシェイプ / モデルシェイプ | シェイプキーの値 |
| メイドボイス / 効果音 | 再生パラメータ |
| メイド衣装 | 現在の装備の表示のみ（`初期化` / `初期値更新` ボタン） |
| メイド脱衣 | スロットごとの表示トグル |
| メイドマテリアル / モデルマテリアル / 背景モデルマテリアル | マテリアルのプロパティ |
| メイド重力 | 重力ウィンドウと同じ行 |
| カメラ / サブカメラ | カメラウィンドウと同じ行 |
| モデル / モデルボーン / 背景 / 背景モデル | Transform（モデルは管理操作行も） |
| 背景色 | 背景色、地面の色・表示・位置・広さ |
| ライト | ライトのパラメータ |
| ステージライト / ステージレーザー | コントローラー（一括設定）と各ライト / レーザー |
| サイリウム | コントローラー、バー設定、持ち手設定、エリア。パターンと移動回転はライブ演出ウィンドウで編集します |
| ポストエフェクト | 各エフェクトのパラメータ |
| PNG配置 | Transform、表示、色、明るさ |
| テキスト | 本文、スタイル、テキスト枠の Transform |
