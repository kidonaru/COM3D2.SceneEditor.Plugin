# モデル系レイヤー

モデル系の 4 レイヤーは、モデルの配置を [ModItemExplorer](https://github.com/kidonaru/COM3D2.ModItemExplorer.Plugin) に任せています。

::: warning ModItemExplorer が必要です
ModItemExplorer を導入していない環境では、モデル系レイヤーはレイヤー一覧に出ません。
モデルを含むタイムラインを読み込んでもモデルは復元されず、ログに `モデル配置プロバイダが無いためモデルを復元できません` と出ます。
:::

## モデルの対応付け

- キーの対象名は `モデルのファイル名 + グループ番号` です。同じファイルを複数置くと 2 つ目から ` (2)` のような番号が付きます
- グループ番号は配置したときに決まり、そのモデルを削除するまで変わりません。並び順を入れ替えてもキーの割り当て先はずれません。削除で空いた番号は次に置いたモデルが使います
- 読み込み時は、同名のモデルがあれば再利用し、無ければ生成し、タイムラインに無いモデルは削除されます
- メイドのボーンへのアタッチ先はキーフレームではなくタイムラインのモデル定義に保存されます。アタッチ先はアニメーションできません

## モデル

配置モデルの位置・回転・拡縮・表示です。ギズモや Inspector、ModItemExplorer で編集します。

| 値 | 補間 |
|---|---|
| 位置 / 回転 / 拡縮 | タンジェント補間 |
| `表示` | なし（区間開始値） |

- モデルの追加・削除に合わせて項目が増減し、追加時は 0 フレーム目にキーが打たれます
- モデルを複製すると、複製元のキーが複製先へコピーされます（モデルボーン・シェイプ・マテリアルも同様）

## モデルボーン

モデル内部のボーンの位置・回転・拡縮です。ボーンウィンドウの `モデル` タブで編集します。

- ボーンウィンドウでチェックしたボーンと、既にキーがあるボーンだけが項目に並びます。1 体で数百本になるためです
- チェックすると 0 フレーム目にキーが打たれ、外すとそのボーンのキーが消えます
- 対象ボーンが 1 本も無いモデルは見出しごと表示されません
- すべてタンジェント補間です

## モデルシェイプ

モデルのシェイプキーの値です。シェイプキーウィンドウの `モデル` タブで編集します。

- 絞り込みのルールはモデルボーンと同じです
- 値はタンジェント補間です
- シェイプキーを持たないモデルは項目が出ません

## モデルマテリアル

モデルのマテリアルです。マテリアルウィンドウの `モデル` タブで編集します。

- チェックしたマテリアルだけが項目に並びます
- 数値はタンジェント補間、色は線形補間です
- 主色・影色・リム色・アウトライン色・発光色・Matcap 色などの色と、`光沢度` / `アウトライン幅` / `リムパワー` / `リムシフト` などの数値を持ちます
