# 背景系レイヤー

## 背景

背景の切り替えです。背景ウィンドウの `背景` タブで編集します。

- 項目は背景名ごとに並び、背景を消した状態は `背景なし` という項目になります
- キーは背景のローカルな位置・角度・拡縮を持ちますが、**一切補間されません**。区間の開始でその背景へ切り替わり、Transform も開始値がそのまま使われます
- 1 フレームに置ける背景は 1 つだけです
- 導入されていない背景を指すキーは、ログに `選択された背景が導入されていません` と出て適用されません

## 背景色

項目は `背景色` と `地面色` の 2 つ固定です。**どちらも補間されず**、区間の開始で切り替わります。なめらかに変えたいときはキーを細かく打ってください。

| 項目 | 値 | 編集場所 |
|---|---|---|
| `背景色` | 色（メインカメラの背景色） | 背景ウィンドウ `背景` タブの `背景色`。アルファを下げると透過 PNG で撮影できます |
| `地面色` | 位置 XYZ、広さ XYZ、色、`表示` | 背景ウィンドウ `地面` タブの `地面を表示` / `地面色` / `位置` / `SX` / `SZ` |

- 地面は表示するまで実体を作りません
- タイムライン設定の `地面色表示を背景表示と連動` が ON で背景が非表示のときは、キーの値に関わらず地面も非表示になります
- レイヤーを削除しても地面は消えません

## 背景モデル

現在の背景に含まれる子オブジェクト（背景構成オブジェクト）を制御対象にして、表示・位置・回転・拡縮をキー化します。背景ウィンドウの `モデル` タブで編集します。

| サブタブ | 内容 |
|---|---|
| `追加` | 背景のツリーからチェックして制御対象に加える / 外す |
| `管理` | 対象ごとの表示トグル、表示名、`複製`、`削除`、Transform |

| 値 | 補間 |
|---|---|
| 位置 / 回転 / 拡縮 | タンジェント補間 |
| `表示` | なし（区間開始値） |

- 同じオブジェクトを複製して複数配置できます
- 背景を切り替えると構成オブジェクトが入れ替わるため、対象が `〇〇 (モデルが見つかりません)` になることがあります。この状態では削除だけできます

## 背景モデルマテリアル

背景モデルのマテリアルです。マテリアルウィンドウの `背景` タブで編集します。

- 値の形式と補間はモデルマテリアルと同じです（数値はタンジェント補間、色は線形補間）
- 絞り込みは無く、対象背景モデルの全マテリアルが項目になります。背景モデルを制御対象に追加した時点で 0 フレーム目にキーが打たれます

## PNG配置

PNG 画像オブジェクトの表示・位置・回転・拡縮・色・明るさです。PNG配置ウィンドウで配置し、パラメータは Inspector で編集します。

- 画像は `Sybaris\UnityInjector\Config\PngPlacement\` と `PhotoModeData\Texture\` から探します（.png / .jpg）
- 外部の PngPlacement プラグインは不要です

| 値 | 補間 |
|---|---|
| 位置 / 回転 / 拡縮 X・Z | タンジェント補間 |
| 色 | 線形補間 |
| `明度`（0〜255） | 線形補間 |
| `表示` | なし |

::: info MTE 固有の値は適用されません
MTE の PNG 配置が持つ左右反転、カメラ追従回転、カメラ相対位置固定、アタッチ、APNG 関連などの値は、XML には保持されますが SceneEditor では適用されません。
:::
