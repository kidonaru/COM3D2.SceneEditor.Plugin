# レイヤー

タイムラインはレイヤー単位で編集します。レイヤーは 6 つのカテゴリに分かれ、タイムラインウィンドウのレイヤー操作行で追加・削除・切り替えを行います（[タイムラインウィンドウ](/timeline/window#レイヤー操作行)）。

## レイヤー一覧

「メイド単位」が ○ のレイヤーはメイド 1 人につき 1 本ずつ作られます。× のレイヤーはタイムラインに 1 本だけです。

### メイド

| レイヤー | メイド単位 | 内容 | 主な編集ウィンドウ |
|---|---|---|---|
| `メイドアニメ` | ○ | ボーン回転、中心ボーンの位置、拡張ボーン、IK 固定、接地、指ブレンド | 編集モードのドラッグ点 / ギズモ、IK、指、ボーン |
| `メイドアニメブレンド` | ○ | 任意の .anm を重ねて再生（アニメレイヤー 2〜8） | Inspector |
| `メイド表情` | ○ | 表情モーフと強制上書き（まばたき抑止） | 表情 |
| `メイド移動` | ○ | メイド全体の位置・回転・拡縮 | ギズモ / Inspector |
| `メイド瞳` | ○ | 瞳の位置・サイズ、顔向き、注視先 | 表情の `視線` タブ |
| `メイドシェイプ` | ○ | 衣装・体のシェイプキー | シェイプキー |
| `メイドボイス` | ○ | ボイスの再生 | サウンドの `ボイス` タブ |
| `メイド衣装` | ○ | 装備アイテムの差し替え | Inspector |
| `メイド脱衣` | ○ | スロット単位の表示 / 非表示 | 脱衣 |
| `メイドマテリアル` | ○ | メイドのマテリアル | マテリアルの `メイド` タブ |
| `メイド重力` | ○ | 髪・スカートの重力 | 重力 |

### その他

| レイヤー | メイド単位 | 内容 | 主な編集ウィンドウ |
|---|---|---|---|

## レイヤーの追加と削除

- `+` コンボから未使用のレイヤーを選ぶと追加され、同時にアクティブになります
- `-` ボタンでアクティブレイヤーを削除します。`メイドアニメ` は削除できません
- 各編集ウィンドウの追加ボタン（下記のレイヤーゲート）からも追加できます
- レイヤーを削除してもシーン上の実体（サブカメラ、地面、モデルなど）は変わりません
- 追加・削除は操作履歴に記録されます

## レイヤーゲート

タイムライン読み込み中に、編集ウィンドウが担当するレイヤーがまだ無いときは、ウィンドウの上部に黄色の注意文とボタンが表示され、以降の項目が操作できなくなります。

| 表示 | 意味 |
|---|---|
| `「〇〇」レイヤーが未登録のためタイムラインに記録されません` | レイヤーが無い状態。下の `「〇〇」レイヤーを追加` ボタンで追加できます |
| `タイムライン側の対象メイドが見つかりません` | メイド単位のレイヤーで、対象メイドがタイムライン側にいない状態 |

ボタンを押すとレイヤーが作られ、タイムラインウィンドウのアクティブレイヤーも切り替わります。
タイムラインを読み込んでいないときはゲートは表示されず、各ウィンドウは従来どおり使えます。
タブの切り替えボタンはゲートの対象外です。

PostEffects.Plugin のウィンドウの `タイムライン` モードにも同じ注意文とボタンが出ます。

## 変更追跡に対応するレイヤー

次のレイヤーは、編集ウィンドウでチェックした項目だけがタイムラインの対象になります（[キーフレーム編集](/timeline/editing#変更追跡チェックによる絞り込み)）。

| レイヤー | チェックする場所 |
|---|---|
| `メイドアニメ`（拡張ボーンのみ） | ボーンの `メイド` タブ |
| `メイド表情` | 表情 |
| `メイドシェイプ` | シェイプキーの `メイド` タブ |
| `メイドマテリアル` | マテリアルの `メイド` タブ |
| `モデルボーン` | ボーンの `モデル` タブ |
| `モデルシェイプ` | シェイプキーの `モデル` タブ |
| `モデルマテリアル` | マテリアルの `モデル` タブ |

`メイドアニメ` の体ボーンと、`背景モデルマテリアル` は絞り込みなしで全項目が対象です。

## 0 フレーム目のキー

新しく作ったレイヤーには 0 フレーム目にキーが入りますが、これは必須ではありません。
0 フレーム目のキーを消すと、先頭のキーより手前のフレームではそのレイヤーは何もしません（`メイドアニメ` は先頭キーのポーズを保ちます）。
`メイド表情` だけは、タイムラインを読み込み直したときに表情の強制上書き設定が 0 フレーム目へ入り直します。
