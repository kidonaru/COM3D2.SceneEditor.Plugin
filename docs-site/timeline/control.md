# タイムライン操作ウィンドウ

メニューバー `Window` → `タイムライン操作` で開きます。
ファイル操作、再生、キーフレーム登録、範囲操作、各種トグルをまとめたパネルで、要素はウィンドウ幅に合わせて自動で折り返します。

::: tip キーボード操作はこのウィンドウが表示中のときだけ有効です
`Enter` や `Space` などのタイムライン用キーは、`タイムライン操作` ウィンドウが表示されている間だけ効きます。
タイムラインウィンドウ本体の表示状態とは関係ありません。
:::

## ファイル・保存

| 要素 | 内容 |
|---|---|
| `ファイル` → `新規作成` | 現在のメイドで新しいタイムラインを作成します。未保存の変更は確認なく破棄されます |
| `ファイル` → `アンロード` | タイムラインを閉じます。確認ダイアログが出ます |
| `ファイル` → `アニメ出力` | モーションを .anm として書き出します |
| `ファイル` → `連番画像出力` | 各フレームを PNG として書き出します |
| `セーブ` | タイムラインを XML として保存します |
| `ロード` | `タイムラインロード` ウィンドウを開きます |
| 状態メッセージ | データ不正時は黄色でエラー内容を表示。通常は `[Enter]キーでキーフレームを登録します` または `[F1]キーで編集モードに切り替えます` |

各操作の詳細は[ファイル管理](/timeline/files)を参照してください。

## フレーム操作

| 要素 | 内容 |
|---|---|
| `アニメ名` | タイムラインの名前。XML ファイル名と .anm の名前になります |
| `最終フレーム` | タイムラインの最大フレーム番号（既定 30）。ラベルをドラッグして変更できます |
| `フレーム` | 現在フレーム。ラベルをドラッグして変更できます |
| トランスポートボタン | 左から `先頭へ` / `前のキーへ` / `前のフレームへ` / `再生`（`停止`）/ `次のフレームへ` / `次のキーへ` / `最終へ`。フレーム・キー移動は押しっぱなしで連続移動します |
| `再生速度` | 0〜2 倍。`R` で 1 に戻します |

再生の挙動は[再生とシーク](/timeline/playback)を参照してください。

## キーフレーム

| ボタン | 内容 | 有効条件 |
|---|---|---|
| `登録` | 編集開始時からの差分をキーフレームとして登録 | 編集モード中 |
| `全登録` | アクティブレイヤーの全項目を現在の値で登録 | 常時 |
| `削除` | 選択中のキーを削除 | キー選択中 |
| `コピー` | 選択中のキーをクリップボードへ | キー選択中 |
| `ペースト` | クリップボードのキーを現在フレームへ貼り付け | 常時 |
| `反転P` | 左右反転して貼り付け。ポーズの左右を入れ替えたコピーを作れます | 常時 |
| `ポーズC` | 現在のポーズをクリップボードへ | 常時 |
| `ポーズP` | クリップボードのポーズをメイドへ適用 | 編集モード中 |

ペーストはコピー元と同じレイヤーにしか行えません。

## 範囲操作

| 要素 | 内容 |
|---|---|
| `A` / `B` | 範囲の開始 / 終了フレーム。グリッドに黄色の帯で表示されます |
| `R` | `A` / `B` を 0 に戻す |
| `範囲選択` | `A` 〜 `B` のキーをまとめて選択 |
| `ﾌﾚｰﾑ挿入` | `A` の位置に `A` 〜 `B` の長さぶん空フレームを挿入 |
| `ﾌﾚｰﾑ削除` | `A` 〜 `B` のフレームを詰めて削除。最低 1 フレームは残ります |
| `ﾌﾚｰﾑ複製` | `A` 〜 `B` を複製 |
| `縦選択` | 現在フレームの縦一列のキーを選択 |

## 操作対象

`操作対象` のコンボでアクティブメイドを切り替えます。メイド単位のレイヤーは、ここで選んだメイドのものが編集対象になります。
切り替えてもレイヤーは作られません（切替先に同種のレイヤーが無ければ、そのメイドの `メイドアニメ` レイヤーへ寄せます）。
レイヤーそのものの選択はタイムラインウィンドウのレイヤー操作行で行います。

まだレイヤーを持たないメイドを選ぶと、現在のレイヤー種類のレイヤーがそのメイド用に自動で作られます。

## トグル

アイコンのトグルです。マウスを乗せると名前が表示されます。

| トグル | 内容 |
|---|---|
| `編集モード` | ポーズ編集モードの ON / OFF。ON にすると再生が止まります（`F1` と同じ） |
| `自動登録` | 各ウィンドウでの操作を自動でキーフレームにします。ON のとき赤く表示されます。既定 OFF |
| `メイド表示` | メイドの表示 / 非表示 |
| `モデル表示` | 配置モデルの表示 / 非表示 |
| `背景表示` | 背景の表示 / 非表示。タイムラインに保存されます |
| `カメラ同期` | カメラ系レイヤーの再生内容を実際のカメラへ反映します。既定 ON。キーの登録可否には影響しません |
| `視野角固定` | カメラ系レイヤー以外を編集中、視野角を 35 に固定します |
| `フォーカス固定` | カメラ系レイヤー以外を編集中、カメラの注視点を操作対象メイドの頭へ寄せます |
| `ポスプロ同期` | ポストエフェクトレイヤーの再生内容を反映します。既定 ON |

`カメラ同期` / `視野角固定` / `フォーカス固定` はカメラ系レイヤーが存在するときだけ表示され、カメラ系レイヤーがアクティブな間は操作できません。
`ポスプロ同期` も同様に、ポストエフェクトレイヤーが存在するときだけ表示されます。
`視野角固定` と `フォーカス固定` を切り替えると自動的に編集モードへ入ります。

::: info カメラ同期 OFF のときのカメラレイヤー
`カメラ同期` が OFF で、かつカメラ系レイヤーがアクティブでないときは、カメラレイヤーは再生に反映されません。`登録` でキーを打てるかどうかは、他のレイヤーと同じくカメラ系レイヤーがグリッドに表示されているかどうかで決まります。
:::
