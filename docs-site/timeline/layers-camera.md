# カメラ系レイヤー

## カメラ

メインカメラの構図と手ブレです。項目は `カメラ` / `手ブレ` / `身長補正` の 3 つで、Camera ウィンドウの `Main` / `手ブレ` タブやゲーム標準のカメラ操作で値を作ります。

### カメラ

| 値 | 既定 | 補間 |
|---|---|---|
| 注視点の位置 XYZ（追従中はオフセット） | — | タンジェント補間 |
| 角度（X = 仰角、Y = 方位角、Z = ロール） | — | タンジェント補間 |
| `距離` | 1 | タンジェント補間 |
| `FoV` | 35 | タンジェント補間 |
| `追従` | -1（追従なし） | なし |
| `追従点` | 股 | なし |
| `向き反映` | OFF | なし |

`追従` にメイドのスロット番号を入れると、そのメイドの `追従点` を基準にした相対位置でカメラが動きます。`向き反映` を ON にするとメイドの向きも反映されます。

### 手ブレ

メインカメラに加える手持ちカメラ風の揺れです。構図には書き込まず、カメラの表示位置と角度にだけ揺れを乗せます。
値は Camera ウィンドウの `手ブレ` タブ、または `手ブレ` 項目を選んだときの Inspector で編集します。

| 値 | 既定 | 補間 |
|---|---|---|
| `位置X` / `位置Y` / `位置Z`（位置振幅、m） | 0 | タンジェント補間（0〜0.2） |
| `回転X` / `回転Y` / `回転Z`（回転振幅、度） | 0 | タンジェント補間（0〜5） |
| `周波数` | 1 | タンジェント補間（0〜5） |
| `シード` | 0 | なし（0〜9999、区間の始点の値を使用） |

- 揺れは再生位置だけから決まるため、スクラブ・再生・連番画像出力で同じ結果になります
- 振幅のキーで揺れのフェードイン / フェードアウトを表現します
- `周波数` が `0` のときは揺れません
- `シード` は補間すると波形が壊れるため、区間の始点の値がそのまま使われます
- 手ブレのキーが無いフレームでは、Camera ウィンドウで編集中の値がそのまま使われます

### 身長補正

作成時と身長の違うメイドでタイムラインを再生したときに、注視点の高さを合わせます。カットごとに、どのメイドの身長に合わせるかを選べます。設定は Camera ウィンドウの `Main` タブと、`カメラ` または `身長補正` 項目を選んだときの Inspector にあります。設定は手ブレと同じくタイムラインとは別に保たれ、タイムラインを読み込んでいなくても選べます。

| 値 | 既定 | 補間 |
|---|---|---|
| 基準メイド（`身長補正` の選択） | なし（補正なし） | 線形補間（下記） |

| 設定 | 内容 |
|---|---|
| `身長補正` | 身長に合わせるメイド。他の項目と同じく、編集モードで変えると `身長補正` 項目のキーとして記録されます |
| `基準身長` | 作成時の、そのメイドの身長（cm、プロフィールの身長）。メイドごとに持ち、タイムラインに保存されます。`取得` で今の身長を取り込み直します |

- 補正の倍率は「基準メイドの今の身長 ÷ 基準身長」です
- 追従なしのキーの注視点の高さだけを、基準メイドの足元を中心に倍率で伸縮します。距離・FoV・角度は変わりません
- 追従中のキーは、追従点がもともと身長に合わせて動くため補正しません
- `身長補正` のキーの間では、前のキーのメイドに合わせた高さから、次のキーのメイドに合わせた高さへなめらかに移ります。カットで切り替えたいときは、切り替えるフレームの 1 つ前で `身長補正` 行の `A` ボタンを押し、前のメイドのままのキーを打ちます
  - キーの間に `身長補正` のキーを足す（レイヤー見出しの `A` による全項目の登録を含む）と、そこで切り替わりが区切られ、そのフレームのカメラの高さが変わることがあります
- `基準身長` は、そのメイドを初めて選んだときに 1 回だけ取り込みます。選び直しや保存で取り込み直すことはありません。Undo / Redo の対象にもなりません
- 補正中にキーを打つと、基準身長での値に戻して記録します。別のメイドで編集しても、作成時のメイドで再生した構図は崩れません
- `身長補正` のキーが当たっている間、編集モードの外では選んだ基準メイドがキーの値に戻ります（手ブレと同じ）。基準メイドを変えるときは、編集モードで選んでからキーを打ちます
- 基準メイドが上下に移動すると、カメラも移動量の (1 − 倍率) 倍だけ上下します
- `身長補正` のキーを含むタイムラインは、手ブレと同じく MTE では開けません
- タイムラインを新規作成・読み込んでも、そのとき選ばれている基準メイドはそのまま引き継ぎます。タイムラインを閉じる（アンロード・別のタイムラインの読み込み・新規作成）と、カメラや手ブレと同じく、そのタイムラインのカメラレイヤーを作る前の基準メイドに戻ります
  - カメラレイヤーの最初のキーには、そのとき選ばれている基準メイド（「なし」を含む）の `身長補正` のキーも入ります。「なし」で作ったタイムラインで後から基準メイドを選ぶと、最初のキーからそのキーまでの間は補正がだんだん強くなります。全区間を補正したいときはフレーム 0 で選びます
  - `身長補正` のキーが無いタイムラインでも、選んでいる基準メイドの身長に合わせて再生時に補正されます。補正したくないときは基準メイドを「なし」にします
- タイムラインを読み込むと、タイムラインに保存された基準身長が優先されます。保存すると、それまでに設定した全メイドの基準身長がタイムラインに書き込まれます
- カメラプリセットとシーンプリセットにも基準メイドと基準身長が保存されます。読み込むと、そのときのメイドの身長に合わせて注視点の高さを補正し、基準メイドの選択も戻します。タイムラインの読み込み中は、設定済みの基準身長をプリセットの値で上書きしません。身長補正に対応する前に保存したプリセットを読むと、基準メイドは「なし」になります

### カメラ同期との関係

- `タイムライン操作` の `カメラ同期`（既定 ON）が OFF で、かつカメラ系レイヤーがアクティブでないときは、カメラレイヤーは再生に反映されません
- `登録` でカメラのキーが打たれるのは、他のレイヤーと同じくカメラ系レイヤーがグリッドに表示されているときです（`カメラ同期` の値には依りません）。表示されていないときはカメラウィンドウに案内と `「カメラ」レイヤーを表示` ボタンが出ます
- `カメラ同期` / `視野角固定` / `フォーカス固定` はカメラ系レイヤーがアクティブな間は操作できません
- カメラは**自動登録の対象外**です。`登録` ボタンか `Enter` で登録してください
- `視野角固定` または `フォーカス固定` が ON の間、アクティブでないカメラレイヤーは `登録` でも記録されません（固定された値がキーに混ざるのを防ぐため）。カメラレイヤーをアクティブにしてから登録してください

## サブカメラ

画面内に小窓（ピクチャインピクチャ）でサブカメラの映像を合成します。

- 台数は Camera ウィンドウの `サブカメラ` タブの `サブカメラ数` で 1〜8 台に増減します。項目は `サブカメラ1` … として台数分並びます
- 読み込んだタイムラインに実体より多い番号のキーがあると、不足分のカメラは自動で作られます
- `サブカメラ` レイヤーを削除すると、増やしたサブカメラは最小数まで減ります。残る 1 台は消えません

| 値 | 既定 | 補間 |
|---|---|---|
| `有効` | ON | なし |
| `位置`（追従中は `オフセット`） | — | タンジェント補間 |
| `回転` | — | タンジェント補間 |
| `FoV` | 35 | タンジェント補間（1〜179） |
| `VP X` / `VP Y` / `VP 幅` / `VP 高` | — | タンジェント補間 |
| `追従` / `追従点` / `向き反映` | -1 / 股 / OFF | なし |

`VP` は画面内の小窓の位置とサイズです。登録と自動登録の扱いはカメラレイヤーと同じです。
