# その他のレイヤーと BGM / 動画

## 効果音

項目は `効果音` の 1 つです。キーに到達した瞬間に鳴らすイベント型で、補間はありません。サウンドウィンドウの `効果音` タブで編集します。

| 値 | 既定 | 内容 |
|---|---|---|
| `SE名` | — | 効果音のファイル名 |
| `再生間隔` | 0 | 0 より大きいと、その秒数ごとに鳴らし直します。`Loop` が ON のときは無視されます |
| `Loop` | OFF | ループ再生 |

- 選べるのはゲーム内蔵の公式効果音です。`効果音` タブの `管理` で任意のファイル名を追加でき、タイムラインに保存されます。拡張子 `.ogg` は自動補完され、実在しないファイルは `ファイルが存在しません` と表示されます
- タイムライン未読み込みでは使えず、`タイムライン読込後に使用できます` と表示されます
- シークを連打すると多重に再生されることがあります

## テキスト

GameView に重ねる字幕テキストです。テキストウィンドウで編集します。

- 項目は `Text0`、`Text1`… で、テキストウィンドウの `テキスト` 行の「追加」「削除」に合わせて増減します（番号タブの `1` が `Text0` に対応します）
- 既定フォントは `Yu Gothic Bold` です。入っていない環境ではフォントを選び直してください

| 値 | 補間 |
|---|---|
| 位置 / 回転 / 拡縮 | タンジェント補間 |
| 色 | 線形補間 |
| `本文` / `フォント` / `サイズ` / `行間` / `整列` / `幅` / `高さ` | なし（区間開始値） |

## BGM と動画

BGM と動画はレイヤーを持たず、タイムラインの設定として保存されます。キーフレームにはなりません。
タイムラインの再生・停止・シーク・再生速度に追従します（[再生とシーク](/timeline/playback#bgm-動画との同期)）。

### BGM

サウンドウィンドウの `BGM` タブで設定します。タイムラインを読み込んでいなくても単独で使えます。

- 対応形式は .ogg / .wav です
- BPM とオフセットを設定すると、グリッドに BPM ラインを表示できます

### 動画

動画ウィンドウで設定します。最大 4 本まで扱え、`動画` 行の「追加」「削除」で増減し、番号タブで編集する動画を選びます。

| 項目 | 内容 |
|---|---|
| `動画パス` | mp4 / avi / wmv / mov / flv / mkv / webm |
| `表示形式` | `プレビュー` / `3Dビュー` / `最背面` / `最前面` |
| `表示サイズ`、位置 | 表示形式ごとの配置 |

先読み時間はタイムライン設定の `動画先読み秒数` で変更します。
