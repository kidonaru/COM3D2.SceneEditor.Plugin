# タイムライン設定

`Window` → `タイムライン設定` で開きます。`個別` / `共通` / `トラック` の 3 タブに分かれています。

| タブ | 保存先 |
|---|---|
| `個別` | タイムライン XML（タイムラインごと） |
| `共通` | `Sybaris\UnityInjector\Config\SceneEditor\Timeline.xml`（全タイムライン共通） |
| `トラック` | タイムライン XML |

共通設定は値を変えてマウスボタンを離した時点で自動保存されます。

## 個別タブ

| 項目 | 既定値 | 内容 |
|---|---|---|
| `格納ディレクトリ名` | （空） | `_Timeline` 配下の保存先サブフォルダ。空ならルート直下 |
| `フレームレート`（`30` / `60` ボタン） | 30 | タイムラインのフレームレート。下限 1 |
| `1フレーム調整` | `1F遅らせる` | 1 フレーム間隔のキーの扱い（`なし` / `1F遅らせる` / `1F早める`）。[再生とシーク](/timeline/playback#1-フレーム調整) |
| `胸(左)の物理無効` / `胸(右)の物理無効` | OFF | 胸の揺れ物理を切り、胸ボーンの回転キーを有効にする。.anm にも記録されます |
| `ループアニメーション` | ON | 出力する .anm をループにする |
| `アスペクト比` の `幅` / `高さ` | 0 | レターボックスの比率。`高さ` が 0 なら非表示。画面の比率より横長なら上下、縦長なら左右に黒帯が出ます |
| `ﾚﾀｰﾎﾞｯｸｽ透過度` | 1.0 | 黒帯の不透明度。0 で完全に透明 |
| `地面色表示を背景表示と連動` | OFF | 背景を非表示にしたとき地面も非表示にする |
| `連番画像出力設定` → `フレームレート` | 30 | 連番画像の出力フレームレート |
| `出力名` | `image_{frame:D6}` | 連番画像のファイル名書式 |
| `画像サイズ` の `幅` / `高さ` | 1920 × 1080 | 連番画像の解像度 |
| `画像出力先を開く` | — | 出力フォルダをエクスプローラーで開く |
| `サムネイル更新` | — | ロード一覧用のサムネイルを撮り直す |
| `個別設定を初期化` | — | 確認後、フレームレート・胸物理・ループ・背景表示・地面連動などを既定に戻す。`最終フレーム` は戻りません |

## 共通タブ

| 項目 | 既定値 | 内容 |
|---|---|---|
| `初期補間曲線` | `Smooth` | 新しいキーの補間プリセット |
| `移動範囲` | 5.0 | 移動系スライダーの値域（1〜100）。動画の 3D ビュー位置と被写界深度のピント距離が参照します |
| `ボイス最大秒数` | 20.0 | ボイスキーの `長さ` の上限（1〜30） |
| `動画先読み秒数` | 0.5 | 動画の先読み時間（0〜1） |
| `背景透過度` | 0.5 | グリッド背景の不透明度 |
| `自動スクロール` | OFF | 再生中に現在フレームを追ってスクロールする |
| `処理時間出力` | OFF | 処理時間をログに出す（デバッグ用） |

## トラックタブ

再生区間を分割するトラックの管理です。詳しくは[再生とシーク](/timeline/playback#トラック)を参照してください。

## 設定ファイルのみの項目

`Timeline.xml` には設定ウィンドウに出ない項目もあります。主なものは次のとおりです。

| 項目 | 既定値 | 内容 |
|---|---|---|
| `isAutoKeyFrame` | `true` | `タイムライン操作` の `自動登録` |
| `isCameraSync` / `isFixedFoV` / `isFixedFocus` / `isPostEffectSync` | `true` / `false` / `false` / `true` | `タイムライン操作` の各トグル |
| `frameWidth` / `frameHeight` / `frameNoInterval` | 11 / 20 / 5 | グリッドの 1 フレーム幅、行の高さ、目盛り間隔 |
| `menuWidth` | 100 | ボーンメニューの幅（`□` ドラッグでも変更可） |
| `thumWidth` / `thumHeight` | 256 / 192 | サムネイルのサイズ |
| `detailTransformCount` / `detailTangentCount` | 16 / 32 | キーフレーム詳細で表示するブロック数と、補間曲線プレビューに重ねる曲線数の上限 |
| `isCurveEditorOpen` / `curveEditorHeight` | `false` / 150 | カーブエディタの開閉と高さ |
| `scaleLinked` | `false` | 拡縮行の XYZ 連動 |
| `timelineBgColor1` などの色 | — | グリッド・メニュー・選択範囲・カーブの各色 |
| `keyBind` | — | キー割り当て（[ショートカット](/timeline/shortcuts)） |

キー割り当てを変える GUI はありません。`Timeline.xml` の `keyBind` 要素を直接編集してください。
