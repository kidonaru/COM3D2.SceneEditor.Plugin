# キーフレーム編集

## 編集モード

タイムラインは編集モード外では毎フレーム再生値を書き戻すため、手でポーズや値を動かしても元に戻ります。
値を変えてキーフレームに焼くには編集モードに入ります。

| 操作 | 内容 |
|---|---|
| `F1` | 編集モードの ON / OFF |
| メニューバー `編集モード` トグル | 同上 |
| `タイムライン操作` の `編集モード` トグル | 同上 |

- 編集モードに入ると再生が止まり、再生を始めると編集モードは解除されます
- 編集モードに入った時点で、各レイヤーの現在値が「編集開始時のスナップショット」として控えられます。`登録` はこのスナップショットからの差分を記録します
- 編集モード中にフレームを移動すると、未登録の変更は捨てられ、移動先フレームの値が新しい基準になります
- 編集モードを抜けると、メイドの位置・回転は編集開始時の値へ戻ります

### 自動編集モード

どのウィンドウでもパラメータを変更すると、自動的に編集モードへ入ります。
そのため、通常は `F1` を意識せずスライダーやギズモを操作できます。

例外として、次の操作は明示的に編集モードへ入っていないと使えません。

- `登録` ボタン（`Enter`）
- `ポーズP` ボタン
- ボーンメニュー項目行の `A` / `D` ボタン

## キーフレームの登録

| 操作 | 内容 | 対象 |
|---|---|---|
| `登録` / `Enter` | 編集開始時からの差分だけを現在フレームへ登録 | 表示中のレイヤー |
| `全登録` / `Shift` + `Enter` | すべての項目を現在の値で登録 | アクティブレイヤーのみ |
| 項目行の `A` | その項目だけを登録 | 1 項目 |
| 項目行の `D` | その項目のキーを削除 | 1 項目 |

変更がない状態で `登録` を押すと何も登録されません。

### 登録の対象範囲

`登録` は、**グリッドに表示されているレイヤー**のうち、編集開始時から値が変わったものに打たれます。表示していないレイヤーには裏でキーが増えません。
表示範囲は[表示モード](/timeline/window#表示モード)で決まり、カテゴリモードならアクティブレイヤーと同じカテゴリ、レイヤーモードならアクティブレイヤーだけです。
カメラとサブカメラだけはさらに、そのレイヤーがアクティブなときにしか登録されません。

表示していないレイヤーの値を変えた場合、そのレイヤーへ切り替えてから `登録` してください。

## 自動登録

`タイムライン操作` の `自動登録` トグル（既定 ON）が有効なら、次のタイミングで現在フレームへ差分が自動登録されます。

- IK ・ボーン・指・顔などのドラッグ編集を離したとき
- 各ウィンドウ（ライト、背景、表情、脱衣、重力、モデル配置など）で値を変更して操作履歴に確定したとき

自動登録には次の条件があります。

- 編集モード中であること（自動編集モードで入った場合を含む）
- 操作したメイドがタイムラインの操作対象メイドと同じであること。別のメイドを触った操作は登録されません
- ライトや背景などメイドに紐づかないレイヤーは、操作対象メイドに関係なく対象（ただし下記の表示範囲には従います）

自動登録の対象範囲は `登録` と同じで、グリッドに表示されているレイヤーだけです。

### 触ったレイヤーへの自動追従

値を変えたレイヤーが表示されていないときは、そのレイヤーがアクティブになります。ライトウィンドウでライトを動かせばライトレイヤーがアクティブになり、`自動登録` が ON ならそのままキーも打たれます。

- `自動登録` トグルの ON / OFF に関係なく働きます（OFF なら切り替わるだけで、キーは `登録` か `Enter` で打ちます）
- 編集モード中だけ働きます（値の変化を編集開始時と比べて判定するため）

- 対象は既にあるレイヤーだけです。レイヤーが無いウィンドウでは、そもそも項目が無効になり追加ボタンが出ます
- 今アクティブなレイヤーの値を変えたときは切り替わりません
- ビューポートでのボーン操作は `メイドアニメ` へ追従します
- カメラとサブカメラは対象外です。アクティブな間は `カメラ同期` などが操作できなくなるためです
- ドロップダウン（コンボボックス）から選んで値を変えた場合は追従しません。左右の矢印ボタンで変えた場合は追従します

::: info カメラは自動登録されません
カメラとサブカメラはカメラ同期で常に動いており、他の操作のたびに意図しないキーが増えてしまうため、自動登録の対象外です。
`登録` ボタンか `Enter` で登録してください。
:::


## 変更追跡（チェックによる絞り込み）

拡張ボーン、表情モーフ、シェイプキー、マテリアル、モデルボーンなど項目数が多いレイヤーは、対応する編集ウィンドウで**チェックした項目だけ**がタイムラインの対象になります。

- チェックを付けると、その時点の値が 0 フレーム目に自動でキー登録されます（履歴名 `〜キーフレーム自動登録`）
- チェックを外すと、その項目のキーは全フレームから削除されます（履歴名 `〜キーフレーム自動削除`）
- 読み込んだタイムラインに既にキーがある項目は、チェックがなくても対象に含まれます

対応するレイヤーとウィンドウは[レイヤー](/timeline/layers#変更追跡に対応するレイヤー)を参照してください。

## コピーと貼り付け

| 操作 | 既定キー | 内容 |
|---|---|---|
| コピー | `Ctrl` + `C` | 選択中のキーをコピー |
| ペースト | `Ctrl` + `V` | 現在フレームを起点に貼り付け |
| 反転ペースト | `Ctrl` + `Shift` + `V` | 左右反転して貼り付け |
| ポーズコピー | `Ctrl` + `Alt` + `C` | 現在のポーズをコピー |
| ポーズペースト | `Ctrl` + `Alt` + `V` | ポーズを適用（編集モード中のみ） |

キーの貼り付け先は、コピー元と同じ種類のレイヤーである必要があります。

## キーフレームの移動と削除

| 操作 | 内容 |
|---|---|
| ドラッグ | 選択中のキーをまとめて移動 |
| `Backspace` / `削除` ボタン | 選択中のキーを削除 |
| 範囲操作 | `A` 〜 `B` の挿入・削除・複製（[タイムライン操作ウィンドウ](/timeline/control#範囲操作)） |

値そのものの編集は Inspector で行います（[キーフレーム詳細](/timeline/inspector)）。

## 複数メイド

- スロット番号はシーン上のメイドの並び順です。メイドの増減は自動で追従します
- メイド単位のレイヤーは、`操作対象` コンボで選んだメイドのものが編集対象になります
- タイムライン作成後にメイドを追加しても、レイヤーは自動では作られません。`+` コンボか、各ウィンドウのレイヤーゲートの追加ボタンで追加します
- Hierarchy でメイドを選択すると `操作対象` も追従します
- タイムラインが参照するメイドがシーンにいない場合、そのレイヤーは何もせず、Inspector には `対象メイドが見つかりません` と表示されます

## 操作履歴（Undo / Redo）

タイムラインの操作は SceneEditor の操作履歴に統合されており、`Ctrl` + `Z` / `Ctrl` + `X` で戻す・進めるができます。

- キーフレームの登録・削除・移動・ペースト、レイヤーの追加・削除、フレーム挿入 / 削除 / 複製、トラックの追加・削除・並べ替え・名前 / 範囲の変更、`最終フレーム` の変更、キーフレーム詳細やカーブエディタでの編集、テンプレート適用などが記録されます
- ドラッグ操作はマウスを離した時点で 1 件として記録されます
- タイムライン読み込み中はシーンの操作（メイドの追加など）は履歴に載りません。各ウィンドウの値変更は自動登録でキーになるため、タイムラインの履歴で戻せます
- 新規作成・読み込み・アンロードを行うと履歴はクリアされます
