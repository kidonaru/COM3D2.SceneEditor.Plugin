# メイド系レイヤー

`メイド衣装` 以外はメイド 1 人につき 1 本ずつ作られます。
編集モード中はメイド系レイヤーの再生適用が止まり、ウィンドウやギズモの操作がそのままキーに焼ける値になります。

## メイドアニメ

メイドのモーション全般を扱う基本レイヤーです。削除できず、0 フレーム目にキーが必要です。

| 項目 | キーが持つ値 | 補間 |
|---|---|---|
| 体ボーン | 回転 | タンジェント補間 |
| `Bip01`（中心ボーン） | 回転 + 位置 | タンジェント補間 |
| 拡張ボーン | 回転 + 位置 + 拡縮 | タンジェント補間 |
| IK 固定（腕・脚の肘 / 膝 / 手首 / 足首、計 8 点） | 位置、`IK固定`、`IKアニメ` | 位置のみ補間。フラグは区間開始値 |
| `接地` | `左足の接地` / `右足の接地` / `床の高さ` / `足首の高さ` / `伸ばす高さ` / `伸ばす角度` / `接地時角度` | 補間なし |
| `指ブレンド`（`右手` / `左手` / `右足` / `左足`） | `開き具合` / `閉じ具合`、指ごとのロックと開閉 | ロック以外は補間 |

- **IK 固定**: `IK固定` ON でその部位を固定します。`IKアニメ` ON にすると固定点の座標がキー間で補間されて動きます。OFF のときは座標を補間せず、フレーム移動で復元したボーン位置を目標にします
- **拡張ボーン**: 衣装 MOD などが持ち込む追加ボーンです。ボーンウィンドウの `メイド` タブでチェックしたものだけが対象になります。項目名は `スロット名/ボーン名` です
- **指ブレンド**: 指ウィンドウの `TL:ブレンド有効` が ON で、かつ編集モード中のときだけ適用されます。ボーンメニューでは `左手指` などの指グループの末尾に並びます
- **頭の回転キー**: メイド目線が顔をカメラへ向ける設定のときは、`Bip01 Head` の回転キーの行は表示されません
- **胸の回転キー**: `Mune_L` / `Mune_R` の行は、タイムライン設定の `胸(左)の物理無効` / `胸(右)の物理無効` が ON のときだけ表示されます

`アニメ出力` で .anm に書き出されるのは体ボーン・中心ボーン・拡張ボーンの回転と位置だけです。IK 固定・接地・指ブレンド・拡縮は .anm に含まれません。

## メイドアニメブレンド

任意の .anm を `アニメレイヤー2` 〜 `アニメレイヤー8` の 7 段に重ねて再生します。

| 値 | 既定 | 内容 |
|---|---|---|
| `アニメ名` | — | .anm のファイル名 |
| `開始時間` | 0 | 再生開始位置（秒、0〜10） |
| `重み` | 1 | ブレンドの重み（0〜1）。**この値だけ補間されます** |
| `再生速度` | 1 | 0〜2 |
| `ループ` | ON | ループ再生 |
| `時間上書き` | OFF | ON にするとキーごとに `開始時間` から再生し直します。OFF なら同じアニメ名が続く限り再生時間を積算します |

編集モード中は再生に反映されません。

モーションレイヤー・移動レイヤーの編集で外れたレイヤーは履歴に積まれ、Ctrl+Z で戻せます。

モーションウィンドウの `適用先` がレイヤーの間は、キー登録で「メイドアニメ」「メイド移動」にキーが入りません（[アニメブレンド](/guide/maid-editing#アニメブレンド)）。このレイヤー自身の値は通常どおり記録されます。

## メイド表情

表情モーフの値と、まばたき抑止の `強制上書き` を扱います。0 フレーム目にキーが必要です。

- 表情ウィンドウでチェックしたモーフだけが対象です（[変更追跡](/timeline/editing#変更追跡チェックによる絞り込み)）。プリセット適用もスライダー操作と同じ扱いです
- 通常のモーフは線形補間、頬や涙などの段階的なモーフは補間せず切り替わります
- タイムライン設定の `表情をタンジェント補間` を ON にすると、通常のモーフはタンジェント補間になり、カーブエディタでタンジェントを編集できます。既存のタイムラインは OFF、新規作成したタイムラインは ON です
- `表情設定` → `強制上書き` は常に存在するキーです。OFF にするとそのフレームからゲーム側のまばたきが戻ります。既定 ON で、キーの無い古いデータは ON として読み込まれます
- 読み込んだタイムラインにキーがあるモーフは、表情ウィンドウのチェックが自動で付きます

::: warning
`強制上書き` のキーは SceneEditor 独自の形式です。これを含むタイムラインは MTE では読み込めません。
:::

## メイド移動

メイド全体の位置・回転・拡縮です。項目は `移動` の 1 つで、ギズモや Inspector で編集します。
位置と拡縮はタンジェント補間、回転は球面補間です。

編集モード中にメイド全体を動かした量は、このレイヤーが無いときは `メイドアニメ` の `Bip01`（中心ボーン）へ書き戻されます。このレイヤーがあるときは中心ボーンへは書き戻さず、`移動` のキーとして登録されます。

## メイド瞳

項目は 6 つ固定です。0 フレーム目にキーが必要です。

| 項目 | 値 | 補間 |
|---|---|---|
| `左瞳位置` / `右瞳位置` | `水平` / `垂直` | タンジェント補間 |
| `左瞳サイズ` / `右瞳サイズ` | `水平` / `垂直` | タンジェント補間 |
| `顔向き` | `水平` / `垂直` | タンジェント補間 |
| `注視` | `注視先` / `対象番号` / `ポイント` | 補間なし |

`注視先` は `手動` / `カメラ` / `メイド` / `モデル` / `マウス` から選びます。`メイド` のときは `対象番号`（スロット番号）と `ポイント`（`顔` / `胸` / `股` / `尻` / `中心` / `左手首` / `右手首`）、`モデル` のときは `対象番号` を使います。

顔・瞳の追従の種類（`メイド目線`）はタイムライン全体の設定で、表情ウィンドウの `視線` タブで選びます。`無し` にするとタイムラインは視線を動かしません。
そらす系の設定のときは、`注視先` が `手動` でも向け先が無効になります。`カメラ` と `マウス` はそらし中でも優先されます。

## メイドシェイプ

衣装・体のブレンドシェイプ（シェイプキー）の値です。表情モーフとは別系統です。

- シェイプキーウィンドウでチェックした項目だけが対象です。チェックすると 0 フレーム目にキーが打たれ、外すと全フレームから消えます
- 値はタンジェント補間です

## メイドボイス

項目は `ボイス` の 1 つです。キーに到達した瞬間に再生するイベント型で、補間はありません。

| 値 | 既定 | 内容 |
|---|---|---|
| `ボイス名` | — | ボイスのファイル名 |
| `ループボイス` | — | ループ再生するボイス名 |
| `開始` | 0 | 開始位置（秒） |
| `長さ` | 0 | 再生する長さ（秒） |
| `Fade` | 0.1 | フェード時間（秒） |
| `音程` | 1 | ピッチ |

サウンドウィンドウの `ボイス` タブで編集します。長さの上限はタイムライン設定の `ボイス最大秒数`（既定 20）です。

## メイド衣装

装備アイテムの差し替えです。項目は装備可能なパーツで、カテゴリごとにグループ化されます。

- キーは `装備名`（ファイル名）と `RID` を持ち、補間せず区間開始で切り替わります
- 専用の編集ウィンドウはありません。ゲーム側や MOD メニューで着替えると、編集モード中の差分として登録されます。Inspector では現在の装備の確認と `初期化` / `初期値更新` ができます

## メイド脱衣

衣装スロットの表示 / 非表示です。0 フレーム目にキーが必要です。

- 項目は `衣装` / `頭部衣装` / `アクセ` / `めくれ` の 4 グループに分かれ、各スロットが `表示` の ON / OFF を持ちます
- 補間せず区間開始で切り替わります
- 脱衣ウィンドウで編集します

## メイドマテリアル

メイドの各スロットのマテリアルです。

- マテリアルウィンドウの `メイド` タブでチェックしたマテリアルだけが対象です
- 数値はタンジェント補間、色は線形補間です

## メイド重力

髪とスカートの重力です。項目は `髪` / `スカート` の 2 つで、重力ウィンドウで編集します。

| 値 | 既定 | 補間 |
|---|---|---|
| `有効` | OFF | なし（区間開始値） |
| `X` / `Y` / `Z` | 0 | タンジェント補間（-1〜1） |

`スカート` は skirt / onepiece / mizugi / panz のスロットに効きます。
重力を一度も使っていないメイドで両端のキーが既定値のときは、何も適用しません。

::: warning
`メイド重力` レイヤーは SceneEditor 独自です。これを含むタイムラインは MTE では読み込めません。
:::
