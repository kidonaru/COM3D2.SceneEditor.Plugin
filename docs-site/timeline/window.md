# タイムラインウィンドウ

メニューバー `Window` → `タイムライン` で開く、キーフレームグリッド本体のウィンドウです。

```
┌──────────────┬────────────────────────────────┐
│ レイヤー操作行   │ フレーム番号バー                   │
├──────────────┼────────────────────────────────┤
│ ボーンメニュー   │ グリッド（キーフレーム）            │
│ （左ツリー）    │                                │
│ [全て畳む]      │                                │
├──────────────┴────────────────────────────────┤
│ ▲ カーブ（カーブエディタの開閉バー）                 │
└───────────────────────────────────────────────┘
```

メイドが未配置、またはタイムラインが未作成のときはグリッドは描画されません。
シーンがタイムラインに対応していないときは `シーンが有効ではありません` と表示されます。

## レイヤー操作行

ボーンメニュー最上段の行です。左から順に並びます。

| 要素 | 内容 |
|---|---|
| 選択コンボ | カテゴリモードでは `カテゴリ名 (レイヤー数)`、レイヤーモードではレイヤー名を選びます。カテゴリを選ぶとそのカテゴリの先頭レイヤーがアクティブになります |
| `-` | アクティブレイヤーを削除します。`メイドアニメ` は削除できません |
| `+` | 現在のメイドでまだ使っていないレイヤーの一覧です。選ぶとレイヤーが追加され、同時にアクティブになります |

### 表示モード

| モード | グリッドに並ぶレイヤー |
|---|---|
| カテゴリモード（既定） | アクティブレイヤーと同じカテゴリのレイヤーすべて |
| レイヤーモード | アクティブレイヤーだけ |

モードはタイムライン設定ウィンドウの `共通` タブにある `カテゴリ表示` トグルで切り替えます（ON でカテゴリモード）。設定に保存されます。

どちらのモードでも、グリッド上での編集（クリック追加・削除・移動）はアクティブレイヤーだけが対象です。
`登録`（`Enter`・`登録` ボタン）と自動登録は、どれもグリッドに表示されているレイヤーだけが対象です（[キーフレーム編集](/timeline/editing#登録の対象範囲)）。

メイド単位のレイヤーは、現在の操作対象メイドのものだけが並びます。カメラや背景などメイドに紐づかないレイヤーは常に対象です。

### アクティブレイヤーの切り替え方

- レイヤー見出し行をクリックする
- ボーンメニューの項目行をクリックする（その項目のレイヤーがアクティブになります）
- グリッド上のキーフレームをクリックする
- 選択コンボで選ぶ
- `+` でレイヤーを追加する

Hierarchy でメイド（配下のボーンを含む）を選ぶと、同じ種類のレイヤーのままそのメイドのレイヤーへ切り替わります。追加ライトを選ぶと `ライト` レイヤーへ切り替わります。

## ボーンメニュー（左ツリー）

| 行の種類 | 内容 |
|---|---|
| レイヤー見出し行 | `▼` / `▶` の折りたたみ記号とレイヤー名。メイド単位のレイヤーは `レイヤー名 (メイド名)` と表示。アクティブレイヤーは文字色が強調されます |
| グループ行 | ボーンセットやモデル名などのまとまり。`▼` / `▶` で開閉し、開閉状態は設定に保存されます |
| 項目行 | ボーンやライトなど個別の項目。選択中は文字色が強調され、グリッド側の行が赤い帯でハイライトされます |

| 操作 | 内容 |
|---|---|
| 見出し行をクリック | そのレイヤーをアクティブにする |
| 見出し行をダブルクリック | 折りたたみの切り替え |
| 項目行をクリック | そのレイヤーをアクティブにして項目を選択（もう一度クリックで解除） |
| `Shift` + クリック | 項目の追加選択 |
| グループ行を選択 | 配下の項目をまとめて選択 |
| `全て畳む` / `全て展開` | 表示中の全レイヤーの折りたたみを一括切替 |
| ボーンメニュー右辺の境界線をドラッグ | ボーンメニューの幅を変更（100〜300px）。境界線にマウスを乗せるとカーソルが左右矢印になります |
| カーブエディタ上辺の境界線をドラッグ | カーブエディタの高さを変更（80〜400px）。カーブエディタを開いているときだけ掴めます |

レイヤーの折りたたみ状態は保存されません。新規作成・読み込み時は全レイヤーが畳まれた状態になります。

### A / D ボタン

編集モード中に、アクティブレイヤーの項目行へマウスを乗せると行の右端にボタンが出ます。
アクティブレイヤーの見出し行にも `A` が出て、そのレイヤーの全項目を現在の値でまとめて登録します（コントロールウィンドウの `全登録` と同じ）。

| ボタン | 内容 |
|---|---|
| `A` | 現在フレームにその項目のキーを追加（キーが揃っていないとき） |
| `D` | 現在フレームのその項目のキーを削除（キーが揃っているとき） |

## フレーム番号バー

グリッド上端の目盛りです。クリックした位置へシークし、そのままドラッグでフレームを連続移動できます。
現在フレームの数字だけ緑色で表示されます。

## グリッド

### 表示要素

| 見た目 | 意味 |
|---|---|
| 白いひし形 | キーフレーム |
| 赤いひし形 | 選択中のキーフレーム |
| 暗いひし形 | その項目のボーンが一部しか揃っていないキー |
| 見出し行のひし形 | 折りたたんだレイヤーの全キーをまとめて表示したもの |
| 緑の縦線 | 現在フレーム |
| 赤の縦線 | アクティブトラックの開始 / 終了位置（[トラック](/timeline/playback#トラック)） |
| 黄色の帯 | 範囲操作の `A` 〜 `B` の範囲（[範囲操作](/timeline/control#範囲操作)） |
| 赤い横帯 | 選択中の項目の行 |
| 色のグラデーション帯 | 色を持つ項目（ライトの色など）のキー間の変化。表示 OFF の区間には出ません |
| 黄色の縦線 | BPM ライン（タイムライン設定の BGM で BPM 表示を有効にしたとき） |

### 操作

| 操作 | 内容 |
|---|---|
| キーフレームをクリック | そのレイヤーをアクティブにしてキーを選択。見出し行のキーはそのフレームの全ボーンを選択 |
| `Shift` + クリック | 追加選択 |
| キーフレームをドラッグ | 選択中のキーをまとめて左右に移動 |
| 何もない場所からドラッグ | 矩形選択。矩形に重なったキーを全レイヤーから選択します。`Shift` を押していれば既存の選択に追加 |
| スクロールバー | 横 / 縦スクロール。ボーンメニューは縦スクロールに連動します |

グリッドのフレーム幅・行の高さ・目盛り間隔はズーム操作では変えられません。設定ファイルの `frameWidth` / `frameHeight` / `frameNoInterval` で変更します（[タイムライン設定](/timeline/settings#設定ファイルのみの項目)）。

タイムライン設定の `自動スクロール` を有効にすると、再生中に現在フレームが中央へ来るようスクロールします。

## カーブエディタ

グリッド下端の `▲ カーブ` を押すと、補間カーブを編集するペインが開きます。
詳しくは[補間とカーブエディタ](/timeline/interpolation)を参照してください。
