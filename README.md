# COM3D2.SceneEditor.Plugin

COM3D2.SceneEditor.Plugin は、3D シーンの描画を移動・リサイズできるウィンドウ（GameView）の中に収め、
ゲーム標準の UI を隠した「エディタ風モード」を提供する UnityInjector 形式プラグインです。
メイドのポーズ・表情・衣装、カメラ、ライト、背景、BGM をその場で編集し、撮影まで完結できます。
