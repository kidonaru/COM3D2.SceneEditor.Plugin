# ステージライトの一方向掃引とフェード

2026-09-12、ユーザー指定により1074～1127Fを再調整した。先行する回転の往復・元姿勢への復帰設定はこの設定で置き換えた。

## 今後の基本方針

- ステージライトは点灯中、一方向へ回転する。
- 明るさはフェードインしてからフェードアウトする。点灯中の小刻みな明滅・反転・急停止は避ける。
- カット開始時点ですでにフェードインの途中にある場合もある。カット先頭を全灯アルファ0に揃えない。
- 向きの準備や変更は消灯中に行う。区間末の数値復元を目的に、点灯中のライトを元の姿勢へ引き返させない。
- 動画で確認できる点灯タイミングを優先し、一定周期・全灯共通のフェードを機械的に付けない。

## 今回の反映

StageLightTimelineLayer / SlotNo 0 の `(1, 2)`、`(1, 3)`、`(1, 6)`、`(1, 9)`、`(3, 0)` の65キーを更新した。Euler Xだけを一定方向へ動かし、Yaw/Rollを固定。ピンク2本・シアン3本の色は維持し、ライトごとに単峰のアルファ推移へ変更した。後半のシアンは遅れて点灯する。

1073Fまでのキーは維持。1074Fで既に見えているライトはフェード途中から始める。1127Fまでに全対象をアルファ0にし、1128F以降も最後の角度・消灯を保持する。旧1128Fの姿勢・色・点灯状態への復帰は撤回した。位置・形状・他レイヤーは変更していない。

XML検査はエラー0・警告0。各フェードの単調増加／減少と終端ゼロを検証し、ゲーム内のキー間速度を照合した。確認フレームは1074・1086・1101・1119・1128F。ゲームへ反映後、表示フレームを作業前へ戻した。
