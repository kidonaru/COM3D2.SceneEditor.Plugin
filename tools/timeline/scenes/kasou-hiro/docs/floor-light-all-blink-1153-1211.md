# 全灯点滅1153～1211Fの修正記録

対象は「仮装狂騒曲 篠澤広129.xml」、ModelMaterialTimelineLayer / SlotNo=0の床ライト24個。2026-09-09に修正。

- ユーザー指定の最大発光値は1。最低値は最大の60％、すなわち0.6。別区間のオレンジ色の発光値2.5を今回へ流用したのは誤りであり、修正済み。
- 水色1153～1188F、ピンク1189～1211F。12F周期（4F増光・4F減光・4F最低値維持）。色・周期は動画を参考にした単純化で、厳密な実測値ではない。
- 毎フレームの材質キーは不要。色を含む全49成分の傾きが変わる点と区間両端を保持する。
- 保持時点は1153、1157、1161、1165、1169、1173、1177、1181、1185、1188、1189、1193、1197、1201、1205、1209、1211。
- 区間内のキー数は1416個から408個へ削減。全24灯は同時に増減光する。
- 現行ModelMaterialTimelineLayerは数値を代表タンジェント、色を線形補間する。数値の代表はeasingスロット0であり、EmissionValueスロット41のタンジェントを直接変更する方式ではない。区間内のIn/Outタンジェントを正規化値1にし、対応するsmoothビットだけ解除して直線補間にする。
- 全整数フレーム・全49成分で削減前後を比較。最大誤差1.11e-16。区間内を0.1F刻みで確認し、発光値0.6～1に収まることを検証した。フレーム間の曲線は以前の毎フレームキーと完全同一ではない。
- 区間外のキーは保持。1152F・1212Fは元の消灯状態へ接続する境界キーであり、点滅区間内の最低発光値とは区別する。
- 保存後のキー内容、対象外レイヤー、XML構文、24モデルの登録を検証。inspect_timeline.pyはエラー・警告とも0。ゲーム内確認は未実施。
