# 955〜1027Fの一方向掃引への更新

2026-09-12、[再現手順](stage-light-video-reproduction.md)の更新方針を「仮装狂騒曲 篠澤広138.xml」の955〜1027Fへ適用した。

## 変更内容

StageLightTimelineLayer / SlotNo=0 の `(1, 2)`、`(1, 3)`、`(1, 6)`、`(1, 9)`、`(3, 0)` を変更。各灯の2回の点灯を、一定速度の一方向掃引と単峰のフェードへ整理した。点灯中の反転・停止・明るさの再上昇を除き、開始時点でフェード途中の明るさを維持した。

位置、RGB、形状、親コントローラー、他レイヤー、対象外キーは維持。既存63キーを更新し、982Fに1キー、1025Fに3キーを追加した。回転XYZのタンジェントとSmoothBitだけを調整し、他成分の補間設定を保った。

| ライト | 1回目の点灯区間 / 度毎F | 2回目の点灯区間 / 度毎F |
| --- | --- | --- |
| `(1, 2)` | 955〜970 / −0.666667 | 985〜1018 / −0.4 |
| `(1, 3)` | 955〜983 / −0.821429 | 1003〜1025 / −0.466667 |
| `(1, 6)` | 955〜979 / −0.291667 | 982〜1009 / +0.3 |
| `(1, 9)` | 955〜991 / −0.777778 | 1003〜1025 / −0.5 |
| `(3, 0)` | 955〜983 / −0.642857 | 1003〜1025 / +0.5 |

回転はEulerXの一軸掃引で、Y=90、Z=0。ゲームは `(1, 9)` のYを同じ姿勢の−270へ正規化する。

## 1F境界と今回の範囲

`MotionPlayData.Setup(SingleFrameType.Delay)` は、1F間隔のキーがあると直前モーションの再生終端を後ろへ延ばす。初期候補の1027F消灯はゲームでは1027Fでまだ明るさが残った。このため3灯の消灯を1025Fに置き、1027Fは消灯後の角度を保持した。修正版では全灯が1027Fに完全消灯する。

今回反映した範囲は955〜1027Fのみ。954F、1028F、1073Fの既存境界キーは変更していない。1028Fには旧設定へ戻るキーがあり、側面 `(3, 0)` は再点灯する。1028F以降の消灯保持・次の点灯準備も変更するかはユーザーへ確認中であり、今回の適用には含めていない。後続1074F以降の演出も維持した。

## 検証

- XML構文、全対象StageLightの23値、有限数値、キー重複、登録、対象外保持を検査。標準inspect_timelineはエラー0・警告0。
- CRLF、BOMなしのUTF-8、対象外レイヤー・登録・設定を保持。元のバイト列へ対象部分だけを置換した。
- ゲームで5灯×73Fの365サンプルを取得。10回すべての点灯で回転反転・停止なし、フェード逆行なし。設定直線との最大角度誤差は0.000059度未満。各点灯の終端アルファは0。
- 995F・1018Fの動画プレビューとゲーム画面を比較。動画との全フレーム自動一致を保証するものではない。
- ゲームの数値差23キーはEulerYの±360度表記のみ。確認中は対象レイヤーを退避し、最後に変更対象67キーだけをマージした。他の未保存状態を維持し、表示フレームを947Fへ戻した。
