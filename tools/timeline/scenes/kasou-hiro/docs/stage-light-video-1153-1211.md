# 1153〜1211Fのステージライト

2026-09-12、`仮装狂騒曲 篠澤広139.xml`を更新。参考は[再現手順](stage-light-video-reproduction.md)と`仮装狂騒曲 篠澤広2.avi`。30fps、動画補正+0.17秒、対象時刻38.6033〜40.5367秒。動画を3F間隔で抽出して目視した近似であり、光源座標の自動復元ではない。

## 変更

`StageLightTimelineLayer / SlotNo=0`の5灯へ、境界を含む22フレーム位置・110キーを追加した。既存キーは変更していない。

| 対象 | 動き |
| --- | --- |
| `(1, 3)` | 先頭から点灯しているシアンの斜光。1156Fを頂点に1174Fまで減光 |
| `(1, 2)` | 左寄りのピンク。1177Fを頂点に1201Fまで減光 |
| `(1, 6)` | 右寄りのピンク。1186Fを頂点に1207Fまで減光 |
| `(1, 9)` | 後半のシアン。1207Fを頂点とし、1211Fにも残光 |
| `(3, 0)` | 前半の弱いシアン補助光。1174Fまでに消灯 |

今回のカメラは正面カットと向きが異なるため、位置をこのカット向けに設定した。太さ・長さ等の形状値は各灯の既存値を保持。ピンクはRGB `(1, 0.25, 0.7)`、シアンは`(0.18, 0.95, 1)`。各灯の回転は一方向・一定角速度で、点灯中の往復や姿勢復元は行わない。

数値は[設定JSON](../plans/stage-light-video-1153-1211.json)。JSONの1211Fのアルファは設計曲線の端点であり、そのフレームのキーは生成しない。実際の1211Fのシアンアルファは0.34375。

## 境界と1フレーム遅延

1152Fに元の消灯状態を置き、それ以前への補間の波及を防いだ。動画は1212Fで別カットに切り替わる。1212Fには元の消灯状態を置き、回転はその時点まで進めた角度を保持する。以後の可視状態は元の消灯のまま。

最初の候補では1211Fと1212Fにキーを置いたが、`SingleFrameType=Delay`により末尾が減速し、実機で最大約0.483度の差が出た。1211Fのキーを除き、1210→1212Fの2フレームで線形回転と減光を補間することで解消した。タイムライン全体のDelay設定は変更していない。

## 検証

- 原本と候補のXML検査はエラー0・警告0。StageLightの23値、有限値、重複キー、登録済み対象を別途検証。
- 挿入ブロックを取り除くと原本のバイト列に完全一致。他レイヤー、既存キー、改行・BOMを保持。
- ゲーム内の対象レイヤーと原本の一致を確認してから、照明レイヤーだけ候補を読み込んだ。他レイヤーの未保存編集を読み直す処理は行っていない。
- 1153F・1177F・1211Fをゲーム画面で目視。画角・舞台配置等の差があり、動画との完全一致を保証するものではない。
- 1153〜1211Fの全整数フレームをゲームで評価。5灯のEulerXの最大誤差は約0.00000763度。フェードは全灯で単峰。
- 1128・1140・1152・1212・1250・2739Fの対象5灯のアルファ0をゲームで確認。
- 原本ハッシュ再確認、一意な同フォルダーバックアップ、保存後の候補とのバイト一致を検証。

作業用の抽出画像、生成処理、候補XML、検証・反映JSONは`tools/timeline/work/kasou-hiro/stage-light-1153-1211/`。反映記録`applied.json`にバックアップの絶対パスを保存した。生成処理は当時の原本ハッシュを前提とする一時処理であり、編集後XMLへ再実行しない。
